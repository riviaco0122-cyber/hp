下田の空き家を宿にして1年｜NODE Shimodaの実績とインバウンド需要から見えた、小さな宿が成り立つ条件

公開日 2026.09.30 更新日 2026.09.30 読了目安 約5分 執筆：RIVIA MEDIA 編集部

静岡県下田市で空き家を改修し、2025年7月に開業した滞在型の宿「NODE Shimoda」。開業から1年の運営実績と、海外ゲストの傾向・季節ごとの需要の変化から見えた、地方の小さな宿が事業として成り立つ条件を紹介します。

  • 開業2年目の春〜夏は、稼働率がおおむね7〜9割で推移し、売上は各月とも予算を大きく上回りました。
  • ゲストの中心は海外からの旅行者。OTA（予約サイト）を軸にした集客の型をつくったことで、立地や担い手が変わっても再現しやすい運営になっています。
  • 夏と冬で単価と需要が大きく変わるため、季節ごとに価格と販売の打ち手を変えることが、年間の収益を安定させる鍵です。

NODE Shimodaとは：下田の空き家を改修した滞在型の宿

NODE Shimodaは、静岡県下田市の旧町内にある空き家を借り受け、リノベーションして2025年7月に開業した一棟貸しの滞在型の宿です。ペリーロードなどの観光スポットへ徒歩圏内という立地で、旅館業（簡易宿所）の許可を取得して運営しています。

RIVIA&CO.のメンバーが、改修から運営・集客・DX化（多言語AIチャットボットの導入など）までを自ら手がけてきました。Airbnbでは評価4.88（51件）をいただいています。

この記事では、開業から約1年の運営を振り返り、地方の小さな宿が事業として成り立つために何が効いたのかを、実績データの傾向とあわせて紹介します。

初期投資は「借りて、直して、しつらえる」で数百万円台に

建物は購入せず賃貸で借り受け、投資を内装の改修と家具・家電・寝具などのしつらえに絞りました。初期投資の総額は数百万円台で、その大半を内装改修が占めています。

項目初期投資に占める割合（目安）
内装改修工事約8割
家具・家電・寝具・日用品など約2割

※ 自社の会計データをもとにした概算です。

また、下田市の補助金も活用しました。補助金は後払いが原則のため、資金計画には立て替えの期間も織り込んでおくことが大切です（補助金の注意点はこちらの記事で解説しています）。開業後には、運営を回しやすくするための設備（ガス衣類乾燥機など）も追加しました。

開業2年目の春〜夏は、稼働率7〜9割・売上は予算を大きく上回る

開業2年目にあたる2026年度は、春から夏にかけて次のような傾向になりました。

指標2026年4〜8月の傾向
稼働率おおむね7〜9割で推移
予算に対する売上5か月とも予算を上回り、4〜8割増
売上に対する営業利益の割合おおむね半分以上
平均客室単価夏のピークは春の2倍以上

※ 自社の予約・会計データをもとにした傾向です（チェックアウト日基準）。営業利益は、OTA手数料・清掃・家賃・水道光熱費などを差し引いたもので、減価償却費と借入金の返済は含みません。

開業初年度は、レビューがまだ少ない状態からのスタートでした。レビューの蓄積と価格設定の見直しを重ねた結果、2年目は数字が大きく伸びています。1棟の小規模な宿でも、稼働と単価の設計が噛み合えば、しっかりと利益が残ることを実感した1年でした。

インバウンド：ゲストの中心は海外からの旅行者

日本政府観光局（JNTO）によると、2024年の訪日外国人旅行者数は約3,687万人と過去最高を記録しました（詳しくは日本の観光市場のデータ記事で解説しています）。この流れは、東京から少し離れた下田のような地方の町にも確実に届いています。

NODE Shimodaでも、開業以来のゲストの多くを海外からの旅行者が占めています。平均の滞在は2〜3泊と観光地の1泊旅行よりも長く、1週間を超える連泊もあります。

「有名な観光地を慌ただしく巡る」のではなく、「その土地に少し腰を落ち着けて過ごす」。「暮らすように旅する」需要は、地方の小さな町にこそあるというのが、現場で得た実感です。

OTAを軸にした集客で、「再現できる運営」をつくる

NODE Shimodaの予約は、Airbnbを中心としたOTA（オンライン予約サイト）経由が大半です。これは、私たちが意図して選んだ戦略でもあります。

  • 開業初日から世界中のゲストに届く：知名度のない新しい宿でも、OTAに掲載すれば海外の旅行者に見つけてもらえます。
  • レビューが信頼を積み上げる：ゲストの評価が次の予約につながり、評価4.88という実績そのものが集客力になります。
  • 運営の型を横展開できる：掲載ページのつくり方、価格の調整、メッセージ対応などを標準化しておけば、立地や担い手が変わっても同じ水準の運営を再現できます。

この「型」があるからこそ、RIVIA&CO.は他の施設の運営代行や開業支援でも、NODE Shimodaで検証したノウハウをそのまま活かすことができます。今後は、OTAで得た認知とリピーターを土台に、自社サイトからの直接予約も育て、集客の幅をさらに広げていく計画です。

季節ごとに打ち手を変えて、年間の収益を安定させる

下田は海のまちです。夏は需要が集中し、平均客室単価は春の2倍以上になります。一方で、冬は観光客が落ち着く季節です。

そのため、私たちは「一番良い月」ではなく「年間」で収支を組み立てることを大切にしています。夏は需要に合わせて価格を上げて収益を確保し、冬は連泊や長期滞在のプランで稼働を下支えする。季節ごとに価格と販売の打ち手を変えることが、年間の収益を安定させる鍵になります。

1年の運営で得た、小さな宿が成り立つための5つの学び

① 投資は「借りて、直して、しつらえる」に絞る

建物を購入せず賃貸で借りることで、初期投資を内装とお部屋のしつらえに集中できました。開業後の追加工事に備えて、予備費を1〜2割見込んでおくと、運営を始めてから必要になる設備にも柔軟に対応できます。

② 清掃とリネンの段取りまで設計する

予約が続く時期に高い稼働を保てるかどうかは、清掃やリネンの回転で決まります。NODE Shimodaでは開業後にガス衣類乾燥機を導入し、次のゲストを迎えるまでの準備を効率化しました。

③ OTAで「見つけてもらう仕組み」をつくる

OTAを集客の軸に据え、掲載・価格・レビュー対応を標準化することで、再現性のある運営の型ができました。

④ 季節ごとに価格と販売を変える

夏と冬で需要が大きく変わるからこそ、季節に合わせた価格設定とプランづくりが、年間の収益を左右します。

⑤ 許可と補助金は、物件を決める前に確認する

NODE Shimodaでは、年間の営業日数に上限のない旅館業（簡易宿所）の許可を取得しました。許可の要件は改修の設計に直接かかわり、自治体の補助金は申請のタイミングが決まっています。物件を決める前の段階から、制度とスケジュールを確認しておくことが大切です（制度の違いは民泊新法と旅館業の比較記事で解説しています）。

まとめ：地方の小さな宿は、仕組みとデータで事業になる

NODE Shimodaの1年は、地方の空き家を活用した小さな宿でも、海外からの滞在需要をとらえ、再現できる運営の型をつくれば、しっかりと利益の出る事業になることを示してくれました。

RIVIA&CO.は、こうした自社運営の実績とデータをもとに、空き家の活用から宿の開業、運営・集客までを一貫してご支援しています。「自分の物件でも宿にできるか知りたい」という段階から、お気軽にご相談ください。

よくある質問

Q地方の空き家を宿にすると、初期費用はどれくらいかかりますか？
A

建物の状態や改修の範囲、購入か賃貸かによって大きく異なります。NODE Shimodaでは建物を賃貸で借り、内装改修と家具・備品に投資を絞ることで、初期投資を数百万円台に抑えました。物件ごとに建物調査と見積もりを取ることをおすすめします。

Q小規模な宿でも利益は出ますか？
A

立地・価格設定・運営コストの設計次第で、十分に利益が出る可能性があります。NODE Shimodaでは、開業2年目の春〜夏にかけて稼働率がおおむね7〜9割で推移し、売上は予算を大きく上回りました。季節による変動があるため、年間の収支で判断することが大切です。

Q下田のような地方でも海外からのお客様は来ますか？
A

来ます。NODE Shimodaでは、開業以来のゲストの多くが海外からの旅行者で、平均の滞在も2〜3泊と長めです。多言語での案内や、OTAでの情報発信を整えることが重要です。

Q運営をすべて自分で行う必要がありますか？
A

必ずしも必要ではありません。清掃やゲスト対応、価格調整などを外部に委託する方法もあります。RIVIA&CO.では、NODE Shimodaで培った運営の型をもとに、運営の一部または全体を代行する運営委託のご相談も承っています。
