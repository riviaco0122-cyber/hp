下田の空き家を宿にして1年｜NODE Shimodaの売上・利益・稼働率と、インバウンド需要から見えたこと

公開日 2026.09.30 更新日 2026.09.30 読了目安 約6分 執筆：RIVIA MEDIA 編集部

静岡県下田市で空き家を改修し、2025年7月に開業した滞在型の宿「NODE Shimoda」。初期投資、売上・利益・稼働率、海外ゲストの割合や季節変動などの実績データをもとに、小規模宿の運営で見えた課題と学びを紹介します。

この記事のポイント

  • 開業までの初期投資は約490万円（うち内装改修が約395万円）。開業後にも設備の追加で約80万円がかかりました。
  • 2026年度は4〜8月の5か月で、売上約213万円・営業利益約130万円。平均稼働率は約83%で、売上は5か月とも予算を上回りました。
  • 予約の7割以上は海外からのゲスト。売上の約8割をAirbnbが占め、OTAへの依存が今後の課題です。
  • 8月の平均客室単価は4月の2倍以上。季節による単価と稼働の差を前提に、年間で収支を組み立てることが重要です。

NODE Shimodaとは：下田の空き家を改修した滞在型の宿

NODE Shimodaは、静岡県下田市の旧町内にある空き家を借り受け、リノベーションして2025年7月に開業した一棟貸しの滞在型の宿です。ペリーロードなどの観光スポットへ徒歩圏内という立地で、旅館業（簡易宿所）の許可を取得して運営しています。

RIVIA&CO.のメンバーが、改修から運営・集客・DX化（多言語AIチャットボットの導入など）までを自ら手がけてきました。Airbnbでは評価4.88（51件）をいただいています。

この記事では、開業から約1年分の実績データをもとに、「実際にいくらかかり、いくら稼げて、どこでつまずいたのか」をできるだけ具体的に紹介します。

※ 数値は自社の会計・予約データにもとづく概算です（2026年9月時点）。

初期投資は約490万円。開業後にも約80万円の追加投資

建物は購入ではなく賃貸で借り受けているため、初期投資の中心は内装の改修と、家具・家電・備品の購入でした。

項目金額（概算）
内装改修工事約395万円
家具・家電（マットレス、冷蔵庫、洗濯機、テレビ、エアコンなど）約44万円
寝具・日用品などの備品、エアコン設置約48万円
旅館業許可の申請手数料約2万円
開業までの合計約490万円
開業後の追加投資（ガス衣類乾燥機、ガス設備工事など）約80万円

出典：NODE Shimoda 会計データ（2025年6月〜12月の支出を集計）

一方で、下田市の補助金として50万円を受け取ることができました。補助金は後払いが原則のため、いったんは自己資金と借入で立て替えています（補助金の注意点はこちらの記事で解説しています）。

売上と利益：4〜8月の5か月で売上約213万円、営業利益約130万円

開業2年目にあたる2026年度は、4月から8月までの5か月で次のような結果になりました。

月宿泊売上稼働率平均客室単価営業利益
2026年4月約22万円73%約1.0万円約11万円
2026年5月約41万円90%約1.5万円約26万円
2026年6月約32万円73%約1.5万円約18万円
2026年7月約51万円87%約1.9万円約32万円
2026年8月約65万円90%約2.3万円約43万円
5か月合計約213万円平均83%—約130万円

出典：NODE Shimoda 予約・会計データ（チェックアウト日基準）。営業利益は、OTA手数料・清掃・家賃・水道光熱費・通信費などを差し引いた金額で、減価償却費と借入金の返済は含みません。

売上は5か月とも予算を上回り、予算に対する達成率は139〜179%でした。売上に対する営業利益の割合は約6割です。建物を賃貸で借りているため固定費（家賃）はかかるものの、1棟の小規模な宿でも、稼働と単価が噛み合えばしっかりと利益が残ることが分かりました。

ただし、開業直後から順調だったわけではありません。開業初年度（2025年7月〜2026年3月の9か月）の売上は入金ベースで約169万円で、冬の月は10万円台にとどまりました。レビューが蓄積し、価格設定の精度が上がった2年目から、数字が大きく伸びています。

インバウンド：予約の7割以上が海外からのゲスト

日本政府観光局（JNTO）によると、2024年の訪日外国人旅行者数は約3,687万人と過去最高を記録しました（詳しくは日本の観光市場のデータ記事で解説しています）。この流れは、東京から少し離れた下田のような地方の町にも確実に届いています。

NODE Shimodaの開業以来の予約を見ると、予約者名がアルファベット表記の予約が全体の7割以上を占めており、ゲストの中心は海外からの旅行者です。

指標実績（2025年7月〜）
海外ゲストの割合（予約者名からの推計）7割以上
売上に占めるAirbnbの割合約8割（Booking.comが約2割、自社予約は1%未満）
平均宿泊日数約2.8泊
1週間以上の連泊全体の約6%（最長19泊）

出典：NODE Shimoda 予約データ（予約管理システムの記録を集計）

平均2.8泊という数字は、「観光地を1泊で巡る」よりも「その土地に少し腰を落ち着けて過ごす」旅のスタイルを表しています。2週間を超える滞在もあり、ワーケーションや長期休暇での利用も一定数あります。「暮らすように旅する」需要は、地方の小さな町にこそあるというのが、現場で得た実感です。

季節変動：夏の客室単価は春の2倍以上

下田は海のまちです。夏は需要が集中し、2026年8月の平均客室単価は約2.3万円と、4月（約1.0万円）の2倍以上になりました。開業初年度の冬（2025年11月〜2026年1月）は、平均客室単価が1.1〜1.2万円前後、月の売上も10万円台にとどまっています。

そのため、小規模宿の収支は「一番良い月」ではなく「年間」で組み立てることが欠かせません。夏に単価を上げて利益を確保しつつ、冬は連泊割引や長期滞在の受け入れで稼働を下支えする。こうした価格と販売の設計が、年間の利益を大きく左右します。

運営して見えた課題と学び

① 改修費は「開業後」にもかかる

開業までに約490万円を投じたうえで、開業後にも設備の追加で約80万円がかかりました。実際に運営してみて初めて必要性が分かる設備は少なくありません。初期投資の計画には、開業後の追加工事に備えた予備費を1〜2割見込んでおくことをおすすめします。

② リネンの回転が、稼働率の上限を決める

開業から約1か月後に、ガス衣類乾燥機を設置工事込みで導入しました。予約が続く時期は、シーツやタオルを洗って乾かし、次のゲストに備えるまでの時間が運営のボトルネックになりやすくなります。清掃やリネンの段取りまで含めて設計しておくことが、高い稼働を続ける前提になります。

③ OTA依存と手数料

売上の約8割がAirbnb経由で、OTAへの手数料は売上の約15%にのぼります。OTAは集客の入口として欠かせない一方、手数料の負担や、プラットフォームの規約・アルゴリズムの変更に左右されるリスクがあります。自社サイトやリピーター向けの直接予約を育てることが、利益率を高める次の一手です。

④ 冬の閑散期をどう埋めるか

夏と冬で売上が大きく変わるため、閑散期の過ごし方が年間の利益を左右します。連泊や長期滞在のプラン、地域のイベントとの連携など、オフシーズンならではの需要をつくる工夫が求められます。

⑤ 許可と補助金は「タイミング」が大切

NODE Shimodaでは、年間の営業日数に上限のない旅館業（簡易宿所）の許可を取得しました。許可の要件は、改修の設計に直接かかわります。また、自治体の補助金は申請や交付決定のタイミングが決まっているため、物件を決める前の段階から、制度とスケジュールを確認しておくことが大切です（制度の違いは民泊新法と旅館業の比較記事で解説しています）。

まとめ：地方の小さな宿は、データで磨けば事業になる

NODE Shimodaの1年は、地方の空き家を活用した小規模な宿でも、海外からの滞在需要をとらえ、価格と運営を磨き込めば、しっかりと利益の出る事業になることを示してくれました。一方で、改修の追加費用、季節変動、OTA依存といった課題も、実際に運営してみて初めて見えてきたものです。

よくある質問

Q地方の空き家を宿にすると、初期費用はどれくらいかかりますか？
A

建物の状態や改修の範囲によって大きく異なります。NODE Shimodaの場合、賃貸で借りた建物の内装改修と家具・家電・備品の購入で、開業までに約490万円、開業後の設備追加で約80万円がかかりました。物件ごとに建物調査と見積もりを取ることをおすすめします。

Q小規模な宿でも利益は出ますか？
A

立地・価格設定・運営コストの設計次第で、十分に利益が出る可能性があります。NODE Shimodaでは、2026年4〜8月の5か月で売上約213万円に対し、営業利益は約130万円（減価償却・借入返済前）でした。ただし季節による変動が大きいため、年間の収支で判断することが大切です。

Q下田のような地方でも海外からのお客様は来ますか？
A

来ます。NODE Shimodaでは、開業以来の予約の7割以上が海外からのゲストと推計され、平均宿泊日数も約2.8泊と長めです。多言語での案内や、OTAでの情報発信を整えることが重要です。

Q運営をすべて自分で行う必要がありますか？
A

必ずしも必要ではありません。清掃やゲスト対応、価格調整などを外部に委託する方法もあります。RIVIA&CO.では、運営の一部または全体を代行する運営委託のご相談も承っています。
