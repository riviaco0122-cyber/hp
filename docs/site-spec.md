## 1. サイトの目的とデザイン方針

* **目的:** 宿泊施設・空き家・地方ビジネスに課題を持つ方が、自分の悩みに合うサービスを見つけ、無料相談（お問い合わせ）に進むこと。

* **トーン＆マナー:** 全ページ共通で白基調（#FFFFFF）・黒文字（#111111）。罫線は1pxの極細グレー（#EEEEEE）。アクセントカラー（深緑 #1A472A）はロゴの「&」のみに限定。
* **フォント:** 見出し＝Noto Serif JP（Light）、本文＝Noto Sans JP、英字・数字＝Cormorant Garamond（Light）。
* **除外要素:** 「Seminar & Event」「マガジン」「SNSへのリンク」は置かない。
* **技術スタック:** HTML / CSS / JavaScript（外部ライブラリなし）。GitHub → Vercel で公開。

### Mission / Vision / Values
* **ミッション:** 地域に眠る価値を、日本の活力に。 — 空き家や遊休不動産、食や自然、文化や人の営み。地域には、まだ活かされていない価値が数多く眠っています。私たちはその価値を掘り起こし、「まちづくり」と「観光づくり」を通じて、人が訪れ、働き、暮らし続けられる地域を増やしていきます。地域が元気になることが、日本が元気になることだと信じて。
* **ビジョン:** 「暮らすように旅する」滞在を、全国のまちへ。
    1. **見つける（Discover）** — 空き家や遊休不動産、食・自然・文化・人の営みなど、地域に眠る資源を掘り起こします。

    3. **届ける（Deliver）** — WEBマーケティングの力で、その価値を求める国内外の旅行者に確実に届けます。
    4. **循環させる（Circulate）** — 人の流れと雇用を地域に生み、持続可能な経済循環とまちづくりへとつなげます。
* **生まれる価値（3つ）:** 旅行者にはその土地の日常に溶け込む、新しい滞在価値を。 ／ 地域には眠っていた資源が稼ぎ、雇用と交流が生まれる経済循環を。 ／ オーナー様には負担だった資産や施設が、収益を生む事業に変わる未来を。
* **バリュー:** 圧倒的当事者であれ：自ら宿を運営し、現場で確かめたことだけを提案する。 ／ 自ら機会をつくれ：指示を待たず、自ら課題を見つけて動き、次の機会を生み出す。 ／ 想いを、成果で示す：想いだけで終わらせず、数字と結果で応える。 ／ 続く仕組みをつくる：一過性で終わらせず、地域に残り、循環する形を選ぶ。

3. **事業の魅力がWEB上で伝わらず、選ばれない**
