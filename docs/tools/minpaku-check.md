# 民泊できる？1分診断（集客装置 Phase A）の仕様

作成: 2026-11-28（人の依頼「スクリーナーのシミュレーション技術を、問い合わせ前に自分の物件のポテンシャルを確かめられる集客装置にする」）。
社内の民泊スクリーナー（仕入れ用、非公開）の「段階に分けて判定する」考え方を、持ち主向けに裏返したもの。

## 1. ねらい（導線）

```
入口（記事・ガイド・サービスページ） → ① 1分診断（個人情報なし） → 結果
   → ② 「わかったこと／まだわからないこと」を正直に分けて見せる
   → ③ 結果に合ったプラン（借り上げ／買取／開業・運営）の無料相談へ（答えを持ったまま）
```
- **どの結果も行き止まりにしない。** 宿に向かない物件は、買取・借り上げ以外の使い方の相談へ案内する。
- 検索の根拠（2026-11-28、日本・月間）: 「民泊 用途地域」260（取引の意図・競合が弱い）、「民泊 儲かる」260、「旅館業 民泊 違い」260、「空き家 民泊」170、「民泊 収益 シミュレーション」110。
  上位の計算ツールは、1泊の料金・稼働率を**自分で入れる**汎用の計算機ばかり。「この物件で営業できるか」と「実際の宿の数字」をまとめて出すものはない → ここで差をつける。

## 3. 判定（計算はプログラム。数字は下の出典のものだけ）

### 3-1. 営業できそうな制度
- 旅館業（簡易宿所。通年で営業できる）: 用途地域が「第一種住居・第二種住居・準住居」「近隣商業・商業・準工業」のとき「できそう」。（建築基準法 別表第二。第一種住居地域は 3,000㎡以下）
- 住宅宿泊事業（いわゆる民泊新法。**年180日まで**）: 住居専用地域でも届出できる。ただし条例で日数・区域が制限されることがある（住宅宿泊事業法 第18条）。工業専用地域は住宅が建てられないため対象外。
- 市街化調整区域: 旅館業は用途の変更に許可が要り、難しいことが多い。民泊新法は自治体の判断による →「保健所・市町村への事前の相談が必要」。
- マンション・アパートの1室: 管理規約で民泊が禁止されていないことが必要（住宅宿泊事業法の届出の要件）。旅館業は現実的に難しい扱いにし、民泊新法の可能性だけを示す。
- 200㎡超: 旅館業にするには用途変更の確認申請が要る（2019年の建築基準法の改正で、200㎡以下は不要）。
- 用途地域は推定しない（家のまわりの様子などからは確定できないため）。わからないときは、旅館業の許可がとれた場合・民泊新法で届け出た場合の両方の結果（売上の目安つき）を並べ、「まだわからないこと」に「用途地域は私たちが無料で調べます」と出す。
- 用途地域の指定がない区域は、用途地域による建物の制限がないため旅館業「できそう」（市町村の決まりは確かめる）。工業地域は旅館業が建てられないが住宅は建てられるため、民泊新法だけ。
- 売上の目安（年）: 旅館業＝オーナーの事例の月の売上 約40万〜55万円×12（約480万〜660万円）。民泊新法＝それを、下田の宿の1年目と同じくらい（年 約190泊）埋まるとして180泊に減らす（約450万〜610万円）。計算はプログラムで行い、将来の約束ではないと書く。
- 「わからない」は判定を保留し、点数は中間にする。

### 3-2. 点数（100点満点・目安）
| 項目 | 配点 | 決め方 |
|---|---|---|
| 制度 | 40 | 旅館業できそう 40／民泊新法のみ 25／わからない・要相談 20／難しい 0 |
| 災害 | 20 | 色なし 20／わからない 10／色あり 5 |
| 建物の状態 | 25 | すぐ住める 25／手入れが必要 15／大きな修繕が必要 5 |
| 広さ | 15 | 60〜150㎡ 15／150〜200㎡ 12／60㎡未満 8／200㎡超 8 |

70点以上「宿として有望」、45〜69点「条件しだいで有望」、44点以下「宿以外の道も比べたい」。

### 3-3. 出す数字（すべて事例として出典を書く。将来の約束にしない）
- 一棟貸しの宿の売上: **月 約40万〜55万円**（オーナーの事例。`docs/brand/experience.md` 確認済み、サービスページと同じ出典）。
- 埋まり方: 創業メンバーが下田で開業した宿の1年目の月別稼働率（8月58%・9月60%・10月52%・11月33%・12月71%・1月39%・2月57%・3月61%、平均 約53%）。グラフで見せる。
- 民泊新法の場合: 年180日が上限。下田の宿の1年目の稼働率 約53% は年に約190泊ぶん（365×0.53 をプログラムで計算）で、上限に近い → 「同じくらい埋まる宿では、180日の上限で売上が頭打ちになる」と説明する。
- 初期費用: オーナーの事例で 総予算 約350万〜450万円。下田の宿（賃貸・家具家電込み）は 改修 約410万円＋家具・家電・備品 約240万円。
- 「大きな修繕が必要」のときは金額を出さず「見積が必要（事例の範囲を超えることがある）」。

### 3-4. 案内するプラン
| 条件 | 1番目に出す | 2番目 |
|---|---|---|
| 「売りたい」、または制度が「難しい」 | 買取プラン | 借り上げプラン |
| 「貸したい・任せたい」 | 借り上げプラン | 買取プラン |
| 「自分で宿をはじめたい」 | 開業・運営プラン | 借り上げプラン |
| 「まだ決めていない」 | 70点以上: 借り上げ＋開業・運営／45〜69点: 借り上げ／44点以下: 買取 | |

相談の入口は `contact.html`。プランを選んだ状態にし、診断の答えをメッセージ欄に入れて渡す（入力の手間を減らす）。

### 3-5. まだわからないこと（いつも出す）
- 建物の傷み・改修の見積（現地を見ないとわからない）
- 条例の日数の制限、保健所・消防との事前の相談
- その場所の1泊の料金の相場と、予約の入り方
- （マンションのとき）管理規約
→ 「この先は、現地を見て私たちが無料で確かめます」
