## WHO・WHAT・HOW

**ペルソナ（特定の1人・仮）**: 34歳・会社員の「ユキさん」。副業で小さな民泊を始め、部屋の準備はほぼ終わった（またはプレオープン前）。「集客」と聞いても何をすることか分からず、検索窓に「民泊 集客 インスタ」と打った。予約サイトに載せれば自然に予約が入ると思っていたが、同じ地域に似た宿が並んでいるのを見て不安になった。不動産・民泊・法律の知識はゼロ（playbook 13-7）。

**WHO（9segs）**: 「宿をまだ誰も知らない（未認知）×消極〜やや積極」の運営者側の読者。開業前〜直後で、泊まった人（リピーター）がまだいない。悩みの順は、①何から手を付けるか分からない ②誰に向けて作ればよいか決められない ③インスタが必要か分からない ④予約サイト頼みが不安（リサーチメモ 2章。読者の声は X・YouTube 動画タイトルからの数件で、推測を含む）。

**潜在ニーズ（その先の目的）**: 部屋づくりにかけたお金と時間を、無駄にしたくない。予約が入らない理由を知り、少ない手間で「泊まってほしい人」に見つけてもらいたい。本当に怖いのは「作り込んだのに、誰にも選ばれないこと」。

**WHAT（3C → インサイト → ベネフィット → RTB）**
- 読者（Customer）: 手段（インスタ・サイト・広告）の名前から検索している。順番が分からない。
- 競合（Competitor）: 動画・X では「手段の紹介」か「運営代行・サロンへの誘導」が目立つ。「誰に・何を・どこで」を順番に決めさせ、実例でつなげる説明は、確認できた範囲では見当たらない。**ただしWeb上位の記事本文は未確認（リサーチメモ 3章）。公開前に品質管理部か編集長が上位3〜5本を取得して確かめる。確かめるまで「競合が言えていない」とは記事に断定しない。**
- RIVIA（Company）: 創業メンバーが下田で宿を開業したときの経験（確認済み）。「欧米の長期滞在者に絞った → 決める設備が決まった → レビューで評価された」という一本の筋。言えないこと：インスタ・広告・Googleマップの運用実績、予約経路の割合、集客の成果の数字（いずれも experience.md にない）。
- インサイト（本音）: 「部屋は作り込んだのに、予約が入らない気がする。インスタを始めたほうがいいのか、何から手を付ければよいのか分からない」
- ベネフィット: 手段を選ぶ前に、①誰に ②何を ③どこで、の3つを紙に書き出せる。自分の宿の答えが決まり、やること・やらないことが分かる。
- RTB（信じられる根拠）: 下田の宿の実例（確認済み）、simasima夫婦の発言（プレオープン）、民泊総合研究所の発言（入らない物件の原因）、読者の声（名前なしの要約）。公的資料は「誰に」の下調べの入口（観光庁・JNTOの統計ページ）として使う。

**HOW（読者に届く場所）**: Google検索（「民泊 集客 何から」「民泊 集客 方法」「民泊 インスタ」）が主。AI検索で引用されるよう、定義文（「民泊の集客とは〜」）と3つの問いの表を1か所にまとめ、FAQの答えを1〜2文で言い切る。`minpaku-start-steps` と集客の子記事からの内部リンクで回遊を作る。SNS（インスタ）経由の流入は狙わない。

## 競合が言えていないこと（差別化）

1. 手段（インスタ・サイト・広告）の前に、「誰に・何を・どこで」を順番に決める、という入口。初心者が書き出せるワーク（チェックリスト）にする。
2. 「絞ったから、設備が決まり、レビューで評価された」という因果を、実際に宿を開業した人の経験（確認済み）で見せる。
3. 「いまはやらないこと」を決める。小さな宿が全部の手段に手を出すと、どれも中途半端になる（戦略は選ぶこと）。ここは RIVIA の考え方として書く（データで裏づけた主張にはしない）。

## よくある質問（FAQ。5問・本文と一致させる。答えは1〜2文）

1. 民泊の集客とは何ですか？ → 泊まってほしい人に宿を知ってもらい、選んでもらうこと。広告やSNSはその手段の一つ。
2. 民泊の集客は何から始めればよいですか？ → 手段より先に、誰に・何を・どこで届けるかを決める。
3. 泊まってほしい人は、一人に絞らないといけませんか？ → 絞ると写真・設備・料金の判断がぶれにくくなる。ほかの人が泊まれなくなるわけではない。
4. インスタは始めたほうがよいですか？ → 届けたい人が使っているかを確かめてから決める。続ける時間があるかも考える。効果は一律には言えない。
5. 開業したばかりで、レビューがありません。何を優先しますか？ → 公開前に知人に泊まってもらって直す。料金を抑えて評価を集める考え方もある（詳しくは `listing-photo-tips`）。
