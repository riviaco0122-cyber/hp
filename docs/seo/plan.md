- 最初の3〜4か月は、新しいサイトが検索エンジンに評価されるまでの「立ち上がり期間」。この時期は CV ではなく、**表示回数・インデックス・記事の本数（先行指標）** で進み具合を判断する

## 2. 計画の木（どの数字を伸ばせば CV が増えるか）

```
CV（お問い合わせ完了。資料請求＋相談）
 = SEO/AIO からのセッション × CV率
     ├ 検索のクリック = 表示回数 × クリック率（CTR）
     │                  └ 表示回数 ← 記事の本数 × 公開からの月数（立ち上がり）
     └ AI検索からの流入（ChatGPT・Perplexity・Gemini など）
```

毎日の PDCA では、この木の上から順に（表示回数 → クリック → AI検索 → CV）計画との差を見て、いちばん遅れている指標の打ち手から実行する（`tools/plan.py` の LEVERS）。

## 6. 進め方（PDCA）と見直しのルール

- **毎日（Check→Act）**：定期実行の最初に `python3 tools/plan.py check` で今月の実績を取り、計画の日割りと比べる（順調 ≥ 90%・注意 ≥ 70%・遅れ）。遅れている指標のうち、計画の木の上流にあるものの打ち手を、その日の作業の1つ目にする。結果は `docs/seo/plan-tracking.md` に1行ずつ残る
- **毎週月曜（報告）**：`python3 tools/plan.py weekly` で先週の週次レポートを作り、定期実行の完了メールと PR に要点を載せる
- **毎月1日（Plan の見直し）**：前月の実績で、仮定（1記事あたりのクリック・CTR・AI検索の割合・CV率）を見直す。**2か月続けて「遅れ」なら、仮定ではなく打ち手を変える**（記事のテーマ・導線・本数）。計画そのものを下げるときは、PR の「人の確認が必要な点」に理由を書いて人の判断を仰ぐ
- 立ち上がり期間（最初の3か月）は CV の数が小さく、日割りの判定がぶれやすい。この期間は表示回数・クリックの判定を優先する
