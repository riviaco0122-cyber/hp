# 宿の集客と採用の考え方（プロの WEB マーケターの視点・はじめての人向け）

作成: 2026-10-15（編集長）。playbook 1章の柱③「宿の集客」・④「宿の人材・採用」の記事を企画・執筆するときの**共通の考え方**。
読者（民泊・小さな宿の運営者）に何を、どの順番で勧めるかの「芯」をそろえるための資料で、記事にそのまま貼る文章ではない。

> **数字の扱い**：この資料には、サービスの手数料・広告の単価・効果の目安などの数字を書いていない（よく変わり、出典なしに書けないため）。記事で数字を使うときは、playbook のルールどおり、公式ページ（確認した日付つき）・公的な統計・`docs/brand/experience.md` の確認済みの実績だけを使う。

---

## 0. いちばん大事な考え方：集客も採用も「流れ」で考える

集客も採用も、相手が「知る → 興味を持つ → 比べる → 決める → 満足する → 人に勧める」という流れをたどる。
うまくいかないときは、**流れのどこで止まっているか**を探し、そこだけを直す。手当たり次第に手段（SNS・広告など）を増やさない。

| 流れ | 集客（ゲスト） | 採用（働く人） |
|---|---|---|
| 知る | 予約サイト・Googleマップ・検索・SNS で見つかる | 求人媒体・地域のつながり・SNS で見つかる |
| 興味を持つ | 写真・タイトル・口コミ | 仕事内容・働き方・職場の雰囲気 |
| 比べる・決める | 料金・立地・設備・レビュー → 予約 | 条件・時間の融通・安心感 → 応募・面接 |
| 満足する | 清潔さ・説明どおり・対応の速さ | 手順がわかる・相談できる・公平 |
| 人に勧める | 口コミ・リピート・直接予約 | 定着・紹介 |

見る数字（記事でも「まずこれを見ましょう」と勧める）：
- **集客**：予約ページの閲覧数、予約率、稼働率、客室単価、RevPAR（`inn-kpi-basics` の記事）、レビューの点数と件数、直接予約の割合
- **採用**：応募数、面接に来た数、採用数、続いている人の数（定着）、清掃の品質（レビューの「清潔さ」）

## 1. 宿の集客：はじめての人がやる順番

**原則：お金をかける前に、「選ばれる中身」と「無料で載せられる場所」を整える。広告は最後。**

### ステップ0：商品をつくる（ここが弱いと、何をしても予約は伸びない）
- **誰に泊まってほしいか**を1つ決める（例：長期滞在の海外の旅行者、家族連れ、ワーケーション）。決めると、写真・説明文・設備・料金がすべて決まる
  - 一次情報：下田の宿は、欧米の長期滞在の旅行者に絞り、ワークデスク・洗濯乾燥・調理器具をそろえて評価された（`experience.md` 3-2）
- **写真**：明るく、広く、実物どおりに。予約サイトでも Googleマップでも SNS でも、最初に見られるのは写真
- **料金**：周りの宿と比べて決め、季節・曜日・イベントで変える。開業直後はレビューを集めるため控えめにし、評価がそろってから上げる（`experience.md` 3-2）

### ステップ1：予約サイト（OTA）で土台をつくる
- Airbnb・Booking.com などの予約サイトは、最初から旅行者が集まっている「大きな商店街」。開業直後の小さな宿は、まずここで予約とレビューを積み上げるのが近道
- 掲載ページで差がつくところ：タイトル、写真の順番、説明文（誰に向いているか）、設備の登録漏れ、ハウスルール、返信の速さ
- 予約サイトごとに客層・手数料・ルールが違う。**手数料や仕様は必ず公式ページで確認**して書く
- 弱点：手数料がかかる、ルールの変更に左右される → だからステップ3（自社サイト）を並行して育てる

### ステップ2：Googleマップ（Googleビジネスプロフィール・MEO）
- 「地名＋宿」「近くの宿」で探す人は、地図から選ぶ。登録は無料
- やること：正しい名前・住所・カテゴリ、写真をたくさん、営業情報、口コミへの丁寧な返信、近くの見どころの紹介
- 口コミを**お金や特典と引き換えにお願いしない**（Google の規約と景品表示法のステマ規制に触れるおそれ）。「よろしければ感想を」と自然にお願いする
- 仕様は Google の公式ヘルプで確認して書く

### ステップ3：自社サイト（公式サイト）で直接予約を育てる
- 予約サイトで知った人が「公式サイトで予約できないか」と探すことは多い。自社サイトがあると、手数料のかからない直接予約と、リピーターとの関係が持てる
- 最低限：宿の魅力が伝わる写真と文章、空室と料金が見られて予約できる仕組み（予約システム）、アクセス、よくある質問、多言語
- 予約サイトより安くするなどの価格の扱いは、各予約サイトの規約に従う（規約は公式ページで確認）

### ステップ4：SNS（Instagram など）
- SNS は「すぐ予約が増える場所」ではなく、**宿の世界観と周りの体験を伝えて、ファンをつくる場所**
- 続けられる量で：部屋の季節の様子、近くの店や景色、ゲストの過ごし方（載せるときは本人の了承を取る）
- プロフィールに予約への道（自社サイトのリンク）を置く
- インフルエンサーに宿泊を提供して投稿してもらうときは、**広告であることを明示してもらう**（ステマ規制）

### ステップ5：WEB 広告（最後に、少額から）
- 広告は「お金を払って見てもらう」手段。ステップ0〜3が弱いまま広告を出すと、見られても予約されず、お金だけが減る
- 始めるなら：少額で、期間と目的（例：閑散期の平日の予約）を決め、**計測できる状態で**試す。効果は「何円で何件予約されたか」で判断する
- 広告の単価や効果を記事で断定しない

### いつも続けること
- **口コミ（レビュー）**：清潔さ・説明どおり・返信の速さで決まる。すべての口コミに返信する。低い評価にも、言い訳せず事実と改善を書く
- **多言語**：ハウスルール・案内を、文章だけでなく絵（ピクトグラム）でも。自動翻訳と定型文で十分に回せる（`experience.md` 3-2）
- **毎月の振り返り**：上の「見る数字」を月に1回並べ、流れのどこが止まっているかを見て、直すのは1か所ずつ

### よくある失敗（記事で注意を促す）
- 写真と説明が弱いまま、SNS や広告を始める
- 予約サイト1つに頼りきり、手数料やルール変更で苦しくなる
- 口コミへの返信をしない、低評価に感情的に返す
- 数字を見ずに「なんとなく」料金を決め、繁忙期に安く売ってしまう

## 2. 宿の人材・採用：はじめての人がやる順番

**原則：まず「人がやらなくていい仕事」を減らし、残った仕事を、近くの人とわかりやすい手順で回す。**

### ステップ0：仕事を分けて、仕組みで減らす
- 宿の仕事を書き出す：清掃・リネン・消耗品の補充・ゲストとのやりとり・チェックイン・駆けつけ・ゴミ・設備の不具合・予約と料金の管理
- 仕組みで減らせるもの：スマートロックのセルフチェックイン、よくある質問への自動応答（AIチャットボット）、定型文、長期滞在で清掃の回数を減らす（`experience.md` 3-2）
- 残った仕事を「自分でやる／外に頼む／人を雇う」に分ける。少ない件数なら、雇うより地域の人や事業者に頼むほうが始めやすいことが多い

### ステップ1：人を探す（RIVIA が大事にしている順番。人の方針 2026-10-15）
1. **まず、自分で地域の人と仲良くなる**：開業前のあいさつ、近所の店・事業者・自治会とのつながり、地域の行事への参加。小さな宿の人手は、求人広告より「顔見知りからの紹介」で見つかることが多い。近隣との関係は、騒音やごみの心配を減らすことにもつながる（`experience.md` 3-2：工事車両の駐車で指摘を受けた経験）
2. **スキマバイト（単発で働けるアプリ）で、まず一緒に働いてみる**：清掃など、切り分けた仕事を単発でお願いし、仕事ぶりと相性を確かめる。いきなり長く雇う約束をしなくてよいのが利点
3. **合う人には、続けてお願いする形に切り替える**（業務委託や継続の雇用など）。このとき次の2点は、記事で必ず注意を促し、**人の確認の対象**にする
   - スキマバイトのサービスの**利用規約**（サービスの外で直接契約してよいか・その条件）を、公式ページで確認する
   - **業務委託か雇用か**は、契約書の名前ではなく働き方の実態で判断される。指示の仕方・時間の拘束などによっては雇用とみなされることがあるため、断定せず、厚生労働省の公式資料と専門家（社会保険労務士など）への確認を勧める
4. ほかの入口も持つ：近くの個人事業主・副業の人・清掃の事業者・求人媒体・自社の採用ページ
  - 一次情報：下田の宿は、近隣の個人事業主と複業人材に清掃をお願いし、開業2か月目に自分が行かなくても回る体制になった（`experience.md` 3-2）
- スキマバイト・求人媒体のサービス内容・料金・規約は、公式ページで確認した日付つきで書く。特定のサービスをすすめる書き方（宣伝）にしない

### ステップ2：伝わる求人にする
- 仕事内容を具体的に（1回の清掃で何をするか、どれくらいかかるか、どの時間帯か）
- 働く側にとっての良さ（時間の融通、近さ、地域に関われること、やり方を教えてもらえること）を正直に
- 写真で職場（宿）の雰囲気を見せる
- 労働条件の書き方には法律のルールがある（職業安定法の明示事項など）。**記事でこの部分に触れるときは、厚生労働省の公式資料で確認し、人の確認の対象にする**。雇用か業務委託かで扱いが変わる点も、断定せず専門家への確認を勧める

### ステップ3：続けてもらう（定着）— 手順書（マニュアル）がいちばん大事
- **手順書（写真つき）を作る**：誰が来ても同じ品質になるように、清掃の順番・チェック項目・備品の置き場所・ゴミの出し方・終わったときの報告のしかたを、写真つきで1つにまとめる。スキマバイトで初めて来た人でも、手順書を見ればできる状態が目標。手順書があるから、人が入れ替わっても宿が回り、業務委託などで任せる範囲もはっきりする
- 最初は一緒にやって教え、つまずいたところを手順書に足していく
- 終わったら写真で報告してもらい、品質をそろえる（`experience.md` 3-2）
- 感謝と、レビューでほめられたことを伝える。困りごとを聞く
- 繁忙期・閑散期の仕事量を前もって共有し、報酬と時間の融通を公平にする

### よくある失敗（記事で注意を促す）
- 仕事を分けないまま「何でもやってくれる人」を探して、見つからない
- 手順を口で伝えるだけで、人によって清掃の品質がばらつき、レビューが下がる
- 1人に頼りきり、その人が休むと宿が回らない（2人以上に頼めるようにする）

## 3. 記事にするときのルール（企画・執筆・品質管理の共通）

1. **読者は民泊・小さな宿の運営者**。宿以外の業種にも当てはまる一般論にしない（「宿の場合は」を必ず書く）
2. **自分でできる手順を主役にする**。最後に、手が回らない人向けに WEB集客支援・WEB採用支援・運営代行を案内する（宣伝を主役にしない）
3. 上の「やる順番」と食い違うことを勧めない（例：開業直後にいきなり広告を勧めない）。違う順番を勧めるときは、その理由を書く
4. **サービスの仕様・手数料・規約**（Airbnb・Booking.com・Google・Meta・求人媒体など）は公式ページで確認し、確認日を本文か出典に書く。よく変わるので、鮮度管理（playbook 9章）の対象
5. 法律に触れる点（景品表示法のステマ規制、各予約サイトの口コミのルール、職業安定法、労働基準法、外国人材の在留資格）は、公式資料だけを根拠にし、**PR の「人の確認が必要な点」に書く**
6. 一次情報（下田の宿の実例）を、できるだけ1つは入れる。使えるのは `experience.md` の「人が確認済み」の節だけ
