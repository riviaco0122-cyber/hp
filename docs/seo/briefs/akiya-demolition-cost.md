## 体験談の扱い（メモ2-1の注意）

- 使うなら steps か estimate の中で「見積もりは文書で残す」程度。RIVIA 創業メンバーの改修で、3社の見積もりから発注し、完了後の追加請求の経験がある（experience.md 3-2、人が確認済みの節）。
- 建物の解体の経験として書かない。内装の一部解体（間仕切り・押し入れなど）の経験は、建物の解体と混同されるため使わない。解体費用の実額・事例も書かない。
- 補助金の体験（市内工務店との契約が要件）は開業改修向けで解体補助ではないため、補助節では「要項の条件を先に読む」の一般論にとどめ、体験としては書かない。

## meta description 案（50〜140字）

空き家の解体費用は、構造・立地・残置物などで変わります。公的な目安が確認できないため金額は示さず、見積もりの見方、更地にすると外れる固定資産税の特例、自治体の補助、売る・貸す・宿にする場合との比べ方を整理します。

## この記事のポイント（keypoints）

- 解体費用は構造・立地・残置物・アスベストの有無で変わるため、複数社の見積もりで範囲を揃えて比べます。
- 住宅を取り壊して更地にすると、固定資産税の住宅用地の特例が外れて税額が上がる場合があります。
- 国の支援は市区町村向けで、所有者への解体補助の有無や条件は自治体ごとに違います。契約の前に窓口で確認します。
- 解体は、現状のまま売る・貸す・宿にするのと並べて、手取りと将来で比べて決めます。

## FAQ（3問以上）

1. 解体費用の相場はいくらですか？ → 公的な目安は確認できず、構造・面積・立地・残置物・アスベストの有無で変わる。複数社の見積もりで確かめる。
2. 解体すると固定資産税は必ず上がりますか？ → 住宅用地の特例が外れ、上がる場合がある。上がり方は評価額・面積・負担調整などで変わる。自治体によっては解体後の減免があるため税務課で確認。
3. 空き家のままだと、税金が上がりますか？ → 空き家であるだけでは外れない。勧告を受けた場合に特例が外れる。
4. 解体の補助金は誰でも使えますか？ → 自治体ごとの制度で、対象建物・申請時期・条件が違う。着工前に所在地の市区町村に確認。
5. 解体してから売るほうが得ですか？ → 一概に言えない。買主が解体する場合の控除の扱いなどは `akiya-3000man-deduction` で確認し、現状のままの査定と並べて比べる。
