## 2. title が40文字を超える記事

### 判断の考え方

- 判断日は 2026-10-10。公開日が 2026-10-10 以前の記事（6本）は「公開済み」、それより後の記事（4本）は「予約中」とした。
- **公開済み**の記事は、URL とともに検索エンジンにすでに認識されている可能性がある。title を変えると、検索結果に出る文が一時的に変わったり、評価が落ち着くまで時間がかかったりすることがある。そのため、効果がはっきりしているものだけ「おすすめ」とした。基準は次の2つ。
  1. **超過が5文字以上**で、後半が長く、主なキーワードが薄まっている。
  2. 主なキーワードが**先頭から約30文字以内**に入っていない（検索結果の表示は30文字前後で省略されることが多いため、40文字を1〜3文字超えても見え方はほぼ変わらない）。
- 公開済みでも、Search Console のデータは 0 件で、これまでの表示・クリックの実績はない。変える場合は実績がたまる前の**いまが最も影響が小さい**。逆に見送る記事は、8〜12週間後に Search Console で「表示は多いのにクリック率が低い」と分かったときに、下の「将来の案」で見直す。
- **予約中**の記事は、まだ公開前なので変更してよい（指示どおり）。ただし seo_check の警告どおり、予約中の記事も HTML と sitemap にはすでに載っているため、クローラーに読まれている可能性はある。それでも公開前で検索実績がないため、変更する。
- 案はサフィックス「 | 合同会社RIVIA&CO.」を除いて40文字以内。文字数は Python の `len()` で数えた（seo_check と同じ数え方）。
- 断定を避ける表現（「なり得る」など）は `docs/brand/voice.md`・`ng.md` に合わせて残した。
