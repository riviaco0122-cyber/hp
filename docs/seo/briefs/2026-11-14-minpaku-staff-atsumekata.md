## 想定読者・WHO・WHAT・HOW

**想定読者**: 民泊・不動産・税・法律の完全な初心者（playbook 13-7）。開業して数か月〜1年、清掃もゲストへの返事も自分でやってきて、手が回らなくなってきた宿主。副業の人を含む。

**WHO（9segs）**: 「運営中×人に頼んだことがない×消極（自分でなんとかしている）」層。人を頼むことを考えたことはあるが、どこで探すか・どう頼めば安全かが分からず、先送りしている。
ペルソナ（特定の1人、仮）: **44歳・会社員の「ミホさん」。相続した実家を宿にして半年。住まいから車で1時間半。週末に通って清掃し、平日の夜にゲストへ返事をしている。本業の繁忙期に清掃が回らず、レビューで「ほこり」を指摘された。求人を出したことはなく、「アルバイトを雇う」のも「業務委託」も、何が違うのか分からない。**
悩み: ①誰に、どこで声をかければよいか分からない ②何を頼めばよいか自分でも整理できていない ③スキマバイトや業務委託で、法律の面で失敗しないか不安 ④頼んだ人が来られない日に宿が止まるのが怖い ⑤夜中のトラブルで駆けつける人がいない。

**潜在ニーズ（その先の目的）**: 宿のために週末を全部使う生活から抜けて、自分が現地に行かなくても、品質を落とさず宿が回る状態。本当に怖いのは「人に任せたら、清潔さとレビューが落ちる」こと。

**WHAT（3C）**
- 読者（Customer）: 「民泊 スタッフ」で探すと、出てくるのは求人広告と清掃会社の営業ページ。宿主の側から見た「どの仕事を、誰に、どの形で頼むか」の全体図がない。
- 競合（Competitor）: 上位は求人広告（ジモティー・engage・Indeed など）が大半。記事は「清掃の頼み方」「業務委託契約書の書き方（一般）」が中心で、駆けつけ・ゲスト対応まで含めた宿の人手の全体と、2024〜2025年の法令の動き（フリーランス法・スポットワークの留意事項・旅館業の駆けつけの FAQ）は扱っていない見込み（メモ5章。本文は未照合）。

### H2-1. 宿のスタッフは、何から集めればよい？（結論：人を探す前に、仕事を分ける）

### H2-2. 宿の仕事のうち、人に頼むのはどれ？（仕組みで減らせる仕事と分ける）
- 結論の1文: チェックインと、よくある質問への返事は仕組みで減らせます。人に頼む仕事として残りやすいのは、清掃・リネン・補充と、トラブルの駆けつけです。
- 図表案（**比較テーブル → スマホはカルーセルカード**。列は3つ：仕事／仕組みで減らせるか／頼める相手）。行は8つ：清掃・リネン／消耗品の補充・ゴミ／ゲストへの返事／チェックイン・鍵／トラブルの駆けつけ／設備の不具合／予約と料金の管理／近隣とのやりとり。例「チェックイン・鍵 → スマートロックで減らせる → 人は要らないことが多い」「駆けつけ → 減らしにくい → 近くの人・管理業者（H2-3）」。セルに長文を入れない。
- 根拠:
  - 下田の宿（確認済み 3-2）：長期滞在とセルフチェックインを前提にして清掃の回数を抑えた。スマートロック、自動翻訳と日英の定型文、過去の質問をまとめた FAQ を読み込ませた AI チャットボット（ノーコード）。
  - 9-1（確認済み・エリアは伏せる。「アキヤドの運営チームが関わる3物件」）：質問・依頼408件のうち、上位6種類（住所・アクセス／設備の有無／チェックイン時間の相談／設備の使い方・不具合／名簿／荷物）で約6割。定型文と写真つきハウスガイドで先回りできる → 詳しくは `minpaku-house-guide`。
  - **数字の図（棒グラフ・4本以内、1本だけ強調色）**: 厚労省「一般職業紹介状況（令和8年9月分）」参考統計表7-1（常用・パート含む、原数値）の有効求人倍率：職業計 1.08倍／接客・給仕職業従事者 **2.31倍**（強調）／飲食物調理従事者 2.26倍／清掃従事者 1.14倍。「だから何か」の1〜2文：接客は求職者1人に約2件の求人があり、集めにくい。清掃は職業計に近い。だから、接客にあたる仕事（チェックイン・返事）は仕組みで減らし、清掃は地域で探す、が順番の理由になる（**RIVIA の見方として書く**）。
  - 図の下の※注記（必須）: ハローワークを通した求人・求職だけの数字で、民間の求人サイトやスキマバイトは入らない。月によって動く原数値。接客・給仕は飲食店なども含み、宿泊業だけの数字ではない。
- 親への1文: 清掃を1回ごとに頼むか月定額にするかで費用の見方も変わる → `minpaku-break-even`。
- つなぎ: 「減らしにくい仕事の中でも、急ぎで決めておきたいのが駆けつけです」

### H2-3. トラブルの駆けつけは、何分で行ける人に頼む？
- 結論の1文: 民泊新法の民泊では、苦情があってから30分以内（交通事情で60分以内）に現地へ行けることが目安です。旅館業の簡易宿所では、緊急時におおむね10分程度で駆けつけられる体制が望ましいとされ、遠隔での対応や委託も認められています。
- 中身を2つの小見出し（h3）に分ける（**宿主が直接集める話と、管理業者の再委託の話を混ぜない**。メモ D の注意）:
  - h3「民泊新法の民泊：家主不在なら、管理業者の仕事になる」: 家主が不在なら、管理の業務は登録を受けた住宅宿泊管理業者への委託が原則（詳しくは `minpaku-seisou-kojin-kakunin`・`minpaku-management-company`。ここは1〜2文）。管理業者は、宿主の承諾と契約の定めがあれば、業務の一部を再委託できる（全部は不可・責任は管理業者）。→ 駆けつけや清掃を地域の人が担う形はありうるが、契約するのは管理業者、という整理。根拠：観光庁 民泊制度ポータル「よくあるご質問」「住宅宿泊管理業者の業務」（メモ D）。
  - h3「簡易宿所：10分は目安で、遠隔や委託もできる」: 根拠は厚労省 事務連絡「旅館業における衛生等管理要領の改正（令和7年3月11日付）に関するFAQ」問3〜6・11（メモ E）。10分の範囲に事務所を機械的に求める趣旨ではない／自治体が長い時間を定めてもよい／徒歩に限らない／状況を把握して遠隔で対応してもよい／駆けつけなどは委託できるが、営業者が状況を把握・指示できる連絡体制、委託先の緊急時の体制、委託先の連絡先をゲストに知らせることが必要。
  - 最後の1文: 実際の基準は都道府県などの条例・細則で決まるので、自分の地域の基準を保健所で確かめる。
- **公開前の必須の照合（ゲート）**: 2026年1月20日付の新しい通知（厚労省 https://www.mhlw.go.jp/content/001438962.pdf 、メモ E）で、10分・遠隔・委託の記述が変わっていないかを、編集長が `tools/fetch_text.py` で本文照合する。照合できなければ、簡易宿所の段落は「10分程度が望ましい体制とされてきたが、遠隔対応や委託の条件があり、基準は自治体で違う。保健所で確認」と短くし、FAQ の日付を必ず添える。
- 図表案: **比較カード2枚**（左：民泊新法の民泊／右：簡易宿所）。各カードに「目安の時間」「誰が担えるか」「確かめる先」の3行。
- 体験: **書かない**（下田の宿で誰が駆けつけているかは未確認。人の確認事項2）。下田が簡易宿所であることは、ここでは触れない（体験と結びつけない）。
- 内部リンク: `minpaku-remote-operation`（緊急時の回し方）。
- つなぎ: 「では、清掃や駆けつけを頼める人は、どこで見つけるのでしょう」

### H2-4. 頼める人は、まず地域で探す（声のかけ方と、地域の入口）
- 結論の1文: 小さな宿の人手は、求人広告より、地域の顔見知りからの紹介で見つかることが多いので、まず自分で地域の人とつながります。
- 中身: 開業前のあいさつ、近所の店・事業者・自治会、地域の行事。近隣との関係は、騒音・ゴミの心配を減らすことにもつながる（`minpaku-neighbor-rules` へ1文リンク）。通勤が遠いと続きにくいので、近さを優先する（メモ1章の清掃会社側の声。一般の傾向として1文。名前は出さない）。
- h3「シルバー人材センターも地域の入口」: 原則60歳以上の会員に、清掃などを「請負」で頼める（業務例に清掃がある）。ただし請負では、宿側は会員に作業のやり方をその場で指示できない。担当が日によって替わることがある（ローテーション）→ 仕上がりの基準を手順書で渡す理由になる。民泊の清掃を受けるかどうか・料金は各センターしだいなので、近くのセンターに問い合わせる。根拠：厚労省・全国シルバー人材センター事業協会「シルバー人材センターの適正就業ガイドライン」（2016年。メモ F）。※ 最新版の有無は未確認 → 公開前に編集長が確認（人の確認事項6）。
- 体験（確認済み 3-2）: 下田の宿では、清掃を近隣の個人事業主・複業人材にお願いしている（2回目の言及は「私たちの宿」）。「業務委託に切り替えた」とは書かない（契約形態は未確認。人の確認事項4）。
- 補強（言い過ぎない）: 開業では、経験のある知人の伴走が予定どおりの開業につながった（3-2）。「地域や知人のつながりが、人手にも助けにもなる」程度。採用の話にしない。
- 図表案: 不要（文章と短い箇条書き3つ）。前後の H2 に図があるため。
- つなぎ: 「声をかけた人と、いきなり長く働く約束をしなくてもよい方法があります」

### H2-5. スキマバイトで頼むときに、知っておくことは？
- 結論の1文: スキマバイト（単発で働けるアプリ）は、宿がその日だけ人を雇う形です。まず一緒に働いて仕事ぶりと相性を確かめられる一方、宿の都合で取り消すと休業手当が要ることがあります。
- 中身（3点を**要点カード**に）:
  1. 契約はいつ成立するか: 面接などをしない先着順の募集では、特に取り決めがなければ、働く人が応募した時点で雇用の契約が成立すると一般に考えられる。
  2. 宿の都合で取り消すと: 契約の成立後に、宿の都合で1日休ませたり早く帰したりすると、労働基準法26条の休業にあたり、休業手当を払う必要がある。宿の例（RIVIA の見方として書く）：ゲストのキャンセルで清掃が要らなくなっても、宿の都合の取消しとして扱われうる → 募集は予約が固まってから出す。
  3. 続けて頼みたくなったら: アプリの外で直接お願いしてよいか・その条件は、各サービスの利用規約で決まっている。公式ページで確かめる（サービス名は出さない。人の確認事項5）。
- 根拠: 厚労省「いわゆる『スポットワーク』における留意事項等をとりまとめたリーフレットを作成し…」（2025年7月4日。ページ本文で照合済み。メモ B）。
- **書かない**: スポットワーク協会の「24時間前」ルール、特定アプリのヘルプの中身（いずれも本文未照合）。「私たちもスキマバイトを使って〜」の体験（未確認）。
- 断定を避ける言い方: 「一般に考えられる」「扱われうる」「要ることがある」。休業手当の額・計算は書かない。迷ったら労働基準監督署・社会保険労務士へ。
- 図表案: 3点の要点カード（カルーセル可）。
- つなぎ: 「一緒に働いて合う人が見つかったら、続けてお願いする形を決めます」

### H2-6. 続けて頼むときは、業務委託か雇用か？（業務委託なら、条件を書面などで示す）
- 結論の1文: 業務委託か雇用かは、契約の名前ではなく働き方の実態で決まります。業務委託で頼むなら、宿に従業員がいなくても、仕事の内容や報酬などの条件を、書面やメールなど記録が残る方法ですぐに示します。
- 中身:
  - 実態で決まる: 作業の順番や時間を細かく指示するほど雇用に近づく（労働者性の判断の4項目は `minpaku-seisou-kojin-kakunin` へ。ここは1〜2文。根拠：厚労省「労働基準法における『労働者』とは」、メモ G）。
  - フリーランス法（2024年11月施行）: 業務委託の相手が、従業員を使っていない個人（副業の会社員も含む）なら対象。宿に従業員がいなくても、取引条件の明示が要る。明示する事項は、業務の内容・報酬の額・支払期日・双方の名前・委託した日・作業の日と場所など。従業員を雇っている宿なら、受け取った日から60日以内の支払いや、募集の書き方の決まりも加わる。名前が業務委託でも実態が労働者なら、この法律ではなく労働基準法などが適用される。根拠：公正取引委員会・中小企業庁・厚生労働省 リーフレット（令和8年1月改訂。メモ C）。
  - 「メール・SNS のメッセージでもよい」の細部は本文未照合のため、「書面やメールなど記録が残る方法」までにとどめる。
- 図表案: **表（3列×3行）**「宿の状態／やること（義務）／例」：従業員なし → 取引条件の明示 ／ 従業員あり → ＋60日以内の支払い・募集の書き方・ハラスメント対策の体制 ／ 従業員あり＋1か月以上・6か月以上の委託 → ＋禁止事項・中途解除の予告など（折りたたみ `details.fold` で「示す事項の一覧」と「1か月・6か月の追加の決まり」を開ける形）。
- **頼み方の形の比較カード**（この H2 の末尾。H2-4〜6 のまとめ）: スキマバイト（その日だけ雇う・宿が指示できる・取消しは休業手当）／業務委託（個人に仕事を頼む・取引条件を示す・細かい指示は雇用に近づく）／シルバー人材センター（請負・料金はセンターへ・その場の指示はできない）／管理業者・清掃会社（全部または一部を任せる・`minpaku-management-company`）。4枚、各カード3行。
- 断定を避ける: 「あなたの場合は業務委託でよい」と書かない。個別の判断は社会保険労務士・労働基準監督署・フリーランス・トラブル110番などの公的な相談窓口へ（窓口名を使うなら公式ページで確認）。
- **人の確認事項1との関係**: 既存記事 `minpaku-seisou-kojin-kakunin` の注記「※ 契約書が法律上必要かは、個別の事情で変わります」と、本記事の「業務委託なら取引条件を書面などで示す」がずれて見える。本記事は公的資料どおりに書き、既存記事の注記の扱いは人が判断する。
- つなぎ: 「最後に、人が替わっても宿が回るようにする方法です」

### H2-7. 人が入れ替わっても回るようにするには？（手順書と、2人以上）
- 結論の1文: 写真つきの手順書を作り、最初は一緒に作業して教え、終わったら写真で報告してもらうと、人が替わっても品質がそろいます。
- 体験（確認済み 3-2・3-1-2。下田の言及は「私たちの宿」で、この記事で3回目まで）: 手順書を作り、現地で一緒に清掃し、完了後に写真で品質を確認した。開業2か月目には自分が行かなくても回る体制になった。ゴミは室内にまとめてもらい、清掃をお願いしている人が分別する。開業当時は月1回ほどだった現地への訪問は、いまは数か月に1回ほど。
- 中身: 手順書に入れるもの（清掃の順番・チェック項目・備品の置き場所・ゴミの出し方・報告のしかた）は1行の列挙だけにし、作り方の詳細は `cleaning-linen-operations` へ。頼める人を2人以上にしておく（欠員対策の詳細は `minpaku-seisou-kojin-kakunin`）。感謝とレビューでほめられたことを伝える、繁忙期・閑散期の仕事量を前もって共有する（ガイド2章ステップ3）。
- 心構え（3-2・確認済み）: 創業メンバーは「副業ではなく、もう一つの本業」という心構えで臨んだ。人に頼んでも、宿の責任と品質の基準を決めるのは宿主、という1文に結ぶ（説教調にしない）。
- 図表案: **サイクル図**（手順書を作る → 一緒にやる → 写真で確認 → つまずいた所を手順書に足す）。4項目。
- つなぎ: まとめへ。

### H2-8. まとめ：まず仕事を書き出すことから
- 結論: 仕事を分けて減らし、地域の人 → スキマバイトで一緒に働く → 合う人に続けて頼む、の順で集め、手順書で定着させる。頼み方の形ごとに、休業手当・取引条件の明示・駆けつけの時間の目安を確かめる。
- 次の一歩: 今週やること1つ（宿の仕事を書き出し、H2-2 の表の3列に当てはめる）。
- 相談の案内（宣伝を主役にしない。ガイド3章の2）: 「求人の出し方や、地域で人を集める発信に手が回らないときは、WEB採用支援で一緒に考えます」→ `service-recruit.html`。全部任せたい人は `minpaku-management-company`／運営支援 `service-operation.html`。※ RIVIA が住宅宿泊管理業者であるかのように書かない（playbook 7章）。採用支援の実績数字は書かない（2026-10-15 の方針）。

## FAQ（本文と一致させる。5問）

1. **民泊のスタッフは、求人広告で集めたほうがよいですか。** → 小さな宿は仕事量が少なく、まず地域のつながりで探すほうが始めやすいことが多い。求人を出す前に、仕事を分けて減らす。※ 求人票の書き方には法律の決まりがある（職業安定法）ため、出すときは厚生労働省の資料で確認を。
2. **スキマバイトで頼んだ清掃を、ゲストのキャンセルで取り消したらどうなりますか。** → 先着順の募集では応募の時点で契約が成立すると一般に考えられ、宿の都合で取り消すと休業手当が要ることがある（厚労省 2025年7月）。募集は予約が固まってから出す。
3. **近所の人に業務委託で清掃を頼むとき、契約書は要りますか。** → 相手が従業員を使っていない個人なら、フリーランス法により、宿に従業員がいなくても、仕事の内容・報酬・支払期日などを書面やメールなどで示す必要がある。形式や個別の判断は窓口・専門家に確認。（※人の確認事項1が決まるまで、既存記事とずれない言い方を品質管理部が確認）
4. **駆けつけスタッフは、何分以内に行ける人が必要ですか。** → 民泊新法の民泊は苦情から30分以内（交通事情で60分以内）が目安。簡易宿所はおおむね10分程度の体制が望ましいとされ、遠隔での対応や委託も認められている。基準は自治体で違うので保健所で確認。
5. **シルバー人材センターに宿の清掃を頼めますか。** → 清掃は請負の業務例にあるが、民泊の清掃を受けるか・料金は各センターしだい。請負なので、作業のやり方をその場で指示することはできない。
