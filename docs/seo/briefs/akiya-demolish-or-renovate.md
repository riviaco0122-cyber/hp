## FAQ（3問以上。構造化データと本文を一致させる）

1. 空き家は、解体したほうがよいのですか？ → 一概には言えない。状態・使い道・手元に残るもの・戻せるかで比べる。建物の診断は専門家へ。
2. 解体前に、まず何をすればよいですか？ → 建築士や施工会社に建物を見てもらい、売却・賃貸・改修の見積もりや査定を並行して取る。市区町村で補助や減免の有無を聞く。
3. 自分で解体すれば、費用を抑えられますか？ → 創業メンバーは内装の一部（間仕切りなど）を自分で解体して改修費を抑えたが、建物の解体ではなく、勧めるものでもない。安全面・廃棄物・資格は専門家や自治体に確認。
4. 解体の費用や補助金はいくらですか？ → 建物・立地・自治体で変わるため額は示さない。複数社の見積もりと、所在地の市区町村窓口で確認。
5. 解体を迷っている空き家は、全国にどれくらいありますか？ → 賃貸・売却用・二次的住宅を除く空き家は3,856,000戸（2023年10月、総務省の推計値）。「放置」とは区別。
