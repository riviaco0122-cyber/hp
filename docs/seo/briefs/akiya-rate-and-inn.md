## meta description 案（50〜140字）

空き家率が高い地域は宿に向くのか。住宅・土地統計調査の取得値から、下田市31.3%・静岡県16.7%・全国13.8%を内訳で比べ、計算式つきで読み方を整理します。宿の需要を見る統計と、自分の市町村の調べ方も紹介します。

## この記事のポイント（keypoints）

- 空き家率は「空き家数 ÷ 総住宅数」で、住宅の余り具合を表す数字です。宿泊の需要は表しません。
- 下田市の空き家率は31.3%で、全国13.8%の約2.3倍です。内訳は、賃貸用の割合が低く、二次的住宅と「それ以外」の割合が高くなっています。
- 宿の需要は別の統計で確かめます。静岡県の外国人延べ宿泊者の割合は、2021年度0.6%から2024年度8.7%に上がりました（県全体の値）。
- 自分の市町村の数字は、e-Stat の表1-2-1から調べ、本文の式で内訳を出せます。

## FAQ（5問）

1. 空き家率はどうやって計算しますか？ → 空き家数 ÷ 総住宅数。例: 下田市は 4,170 ÷ 13,330 = 31.3%（令和5年住宅・土地統計調査、2023年10月1日時点）。
2. 空き家率が高いと、宿には向いていますか？ → 空き家率だけでは言えない。住宅の余り具合であって、宿泊需要は別の統計（宿泊旅行統計調査など）や現地で確かめる。
3. 「賃貸・売却用及び二次的住宅を除く空き家」とは何ですか？ → 賃貸用・売却用・二次的住宅（別荘など）のどれにも当たらない空き家の区分。下田市は空き家の48.2%（2,010 ÷ 4,170）、全国は42.8%。物件ごとの状態や活用可否はこの数字からは分からない。
4. 自分の市町村の空き家率はどこで調べられますか？ → e-Stat の住宅・土地統計調査 表1-2-1（統計表ID 0004021421）で市区町村別に見られる。総住宅数と空き家数から本文の式で計算。標本調査の推計値で、端数の丸めがある。
5. 外国人宿泊者の割合は、市町村ごとに分かりますか？ → 本記事で使った表は都道府県単位（静岡県）で、市区町村の割合は示せない。市区町村の需要は、自治体や観光庁の公表資料、現地の宿泊施設の状況で確かめる。
