# SEO / AIO 手順書（全部署共通の判断基準）

暮らす旅の手帖の目的は「空き家オーナー・宿の開業検討者・観光事業者が検索する悩みに答え、サービスページとお問い合わせへつなげる」こと（`docs/site-spec.md` 5-2）。アクセス数そのものではなく、**相談につながる読者を増やすこと**を優先する。

## 1. キーワードの選び方（企画・マーケ部）

- RIVIA のサービス（空き家再生／開業・運営支援／不動産協業／WEB集客／WEB採用）につながる悩みに限る。
- 優先順位: ①Search Console で順位5〜20位・表示が多いもの（既存記事の改善） ②既存記事と重ならない新しい悩み ③季節・制度改正などの時事。
- 1記事＝1つの検索意図。既存記事と意図が重なるなら新記事を作らず既存記事を強化する（共食いを避ける）。
- `docs/seo/keywords.md` に候補・担当記事・状態を記録する。

## 2. 記事の構成（構成担当・執筆担当）

`docs/site-spec.md`「記事ページの構成（SEO・AIO対策）」に従う。要点:

1. タイトル: 検索されるキーワードを前半に。サフィックスを除いて **40文字以内**を目安。
2. meta description: リード文と同じ要約。**50〜140文字**。
3. **この記事のポイント**: 結論を3〜5行で先に示す（AIに要約・引用されやすい）。
4. 見出しは「疑問文」か「結論」の形にする。各見出しの直後の1〜2文で、その問いに答えきる。
5. 数値・制度には必ず出典（公的機関の資料名）を付ける。出典のない数値は書かない。
6. よくある質問（3問以上）＋構造化データ FAQPage。
7. 参考資料、公開日時点の情報である旨の注記、執筆者情報、関連サービスへのリンクと相談ボタン。

## 3. AIO（AIによる検索回答）で引用されるための基準

- 定義文を1文で言い切る（「◯◯とは、△△のことです。」）。
- 比較は表、手順は番号付きリストにする。
- 一次情報を入れる: RIVIA が実際に宿を運営して得た気づき・数値（`docs/brand/experience.md` にあるものだけを使う。作り話は禁止）。
- 他者の一次情報（YouTube・X などで現場の運営者・オーナーが発信している内容、視聴者コメントに出る生の悩み）は、出典（発信者名・URL）を明記して要約で紹介する。集め方と扱い方は `docs/sources/README.md`。
- 著者・運営者の情報（E-E-A-T）を明示する。
- `llms.txt` でサイトの構成と主要記事を AI に案内する。
- 公開日前の記事は HTML・sitemap に出さない（JavaScript を実行しないクローラーにも見えてしまうため）。

## 4. テクニカルSEO（エンジニア部）

`python3 tools/seo_check.py` のエラーは必ず 0 にする。主なチェック項目:

- title／meta description の有無・長さ・重複、canonical、OGP
- h1 が1つ、画像の alt、内部リンク切れ
- 構造化データ（Article／FAQPage／BreadcrumbList）の書式と日付の整合
- sitemap.xml の網羅性と lastmod
- 表示速度: 画像は `images/photos/thumb/` の軽量版をカードに使う。写真は原寸のまま格納し再圧縮しない（site-spec の方針）。

## 5. 品質の採点基準（品質管理部）

各項目を 1〜5 で採点し、**全項目 4 以上で合格**。1つでも 3 以下なら理由を添えて差し戻す（差し戻しは最大3回。3回で合格しなければ PR に「要確認」として残す）。

| 項目 | 5 の状態 |
|---|---|
| 検索意図への回答 | 冒頭のポイントと各見出しの直後で、読者の疑問に答えきっている |
| 正確性 | すべての数値・制度に出典があり、確認できた。断定しすぎていない |
| ブランド準拠 | `docs/brand/` の文体・用語・NG表現を守っている |
| 独自性 | RIVIA ならではの視点・一次情報がある。他サイトの言い換えではない |
| 導線 | 関連サービスと相談ボタンに自然につながっている |
| 技術 | `tools/seo_check.py` のエラー 0、表示崩れなし |

## 6. 人の確認が必要なもの（PR に必ず書き出す）

- 法律・税金・補助金・消防など、間違えると読者に損害が出る記述
- RIVIA の実績・数値・事例（`docs/brand/` にないもの）
- サービス内容・料金・会社情報の変更
- デザイン（CSS）・JavaScript・`vercel.json` の変更
- 記事の削除、URL の変更
