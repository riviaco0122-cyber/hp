# 用語・表記の統一（glossary）

作成: 2026-10-10 ブランド学習係（初版・人の確認待ち）

## 件数の数え方

- `pages/media/*.html`（28記事）を grep で検索した結果です。サービスページなどは別に書いています。
- grep は「行」単位で数えているため、1行に同じ語が2回あっても1件になる場合があります。
- 記事 HTML には、ほかの記事の「カード」（タイトル）と head 内の構造化データ（FAQ・説明文の重複）が入っています。カードのタイトルにある語は全記事で同じ数だけ増えるので、必要なところは「カード分を除いた概算」も書いています。
- **既存記事で多い方を統一表記にしました。** 既存記事の書き換えは行っていません（URL・タイトルを変えないため。直すかどうかは人が判断）。
