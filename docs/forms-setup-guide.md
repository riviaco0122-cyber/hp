# お問い合わせフォームの設置手順（Google Apps Script・はじめての人向け）

お問い合わせを受け取り、**お客様への自動返信（お礼）メール**と**添付ファイルの保存**を無料で行う仕組みを、あなたの Google アカウント（rivia.co0122@gmail.com）に設置します。パソコンのブラウザで行ってください。全部で10〜15分ほどです。

> **Google Apps Script（GAS）とは？** Google が無料で提供している、Gmail・ドライブ・スプレッドシートを自動で動かす仕組みです。プログラムは Claude が用意したので、あなたは「貼り付けて、ボタンを押す」だけです。

## できあがる仕組み

```
お客様がフォームで送信
  → GAS（あなたの Google アカウントの中）が受け取る
     ├ 添付ファイル → Google ドライブの「RIVIA_お問い合わせ_添付ファイル」フォルダに保存（あなたしか見られない）
     ├ 内容 → スプレッドシート「RIVIA_お問い合わせ一覧」に1件1行で記録
     ├ 社内通知 → rivia.co0122@gmail.com にメール（返信すると、お客様に直接届く）
     ├ 自動返信 → お客様に「お問い合わせを受け付けました」のメール（差出人名：合同会社RIVIA&CO.）
     │   └「サービス資料の請求」を選んだ方には、ドライブの資料（PDF）を添付した「資料をお送りします」のメール
     └ メールマガジンの受け取りに同意した方 → スプレッドシートの「メルマガ」列に「希望する」と記録（配信はまだしない）
```

## 1. プログラムを貼り付ける

1. ブラウザで **https://script.google.com/** を開く（rivia.co0122@gmail.com でログイン）
2. 左上の **「＋ 新しいプロジェクト」** を押す
3. 左上の「無題のプロジェクト」という名前を押して、**`RIVIA お問い合わせフォーム`** に変えて「名前を変更」
4. 画面中央に `function myFunction() { ... }` と書かれた欄があるので、**中身をすべて消す**（Ctrl+A（Mac は ⌘+A）で全選択 → Delete）
5. Claude が用意したプログラム（GitHub の `tools/forms/Code.gs`）を **すべてコピーして貼り付ける**
   - GitHub で https://github.com/riviaco0122-cyber/hp/blob/claude/charming-noether-ajeelv/tools/forms/Code.gs を開き、右上の「コピー」ボタン（二重の四角のマーク）を押すと全文をコピーできます
6. 上の **💾（プロジェクトを保存）** を押す

## 2. 一度だけ動かして、権限を許可する

1. 画面上部の「実行」ボタンの左にある関数の選択欄で **`setup`** を選ぶ
2. **「▷ 実行」** を押す
3. 「承認が必要です」と出たら **「権限を確認」** → 自分のアカウント（rivia.co0122@gmail.com）を選ぶ
4. 「Google はこのアプリを確認していません」と出たら、左下の **「詳細」** → **「RIVIA お問い合わせフォーム（安全ではないページ）に移動」** を押す
   - あなた自身が作ったプログラムなので、この表示が出るのは正常です
5. 許可を求める画面で **「許可」**（または「すべて選択」→「続行」）を押す
6. 画面下の「実行ログ」に「フォルダ: …」「スプレッドシート: …」と出れば成功
   - Google ドライブに、フォルダとスプレッドシートが自動で作られています

## 3. 公開（デプロイ）して、URL を受け取る

1. 右上の青いボタン **「デプロイ」** → **「新しいデプロイ」** を押す
2. 「種類の選択」の歯車マーク ⚙ を押して **「ウェブアプリ」** を選ぶ
3. 次のように設定する
   - 説明：`サイトのフォーム`（何でもよい）
   - 次のユーザーとして実行：**「自分（rivia.co0122@gmail.com）」**
   - アクセスできるユーザー：**「全員」**
     - サイトを見に来たお客様が送信できるようにするための設定です。お客様からは、送信の受け口になるだけで、あなたのドライブやメールの中身が見えることはありません
4. **「デプロイ」** を押す
5. 「ウェブアプリ」の欄に表示される **URL（`https://script.google.com/macros/s/……/exec`）をコピー** して、Claude に送る
   - この URL は秘密の情報ではないので、チャットに貼って大丈夫です
   - 確認したい場合は、その URL をブラウザで開くと `{"ok":true,...}` と表示されます

## 4. このあと Claude がやること

- サイトのすべてのフォームの送信先を、この URL に切り替えます（添付欄はそのまま残せます）
- ボット（自動の迷惑送信）を防ぐ仕組みを、フォームに追加します
- PR を作るので、Vercel のプレビューで**テスト送信**してから、マージしてください
  - テスト送信すると、①社内通知 ②自動返信（入力したアドレス宛て）の2通が届き、スプレッドシートに1行増えます

## 5. 資料請求に送る資料（PDF）を設定する・差し替える

フォームで「サービス資料の請求」（アキヤドでは「サービス資料がほしい」）を選んだお客様には、自動返信メールに資料の PDF が添付されて届きます。どの PDF を送るかは、次の手順で決めます。**資料を差し替えるときも同じ手順です（プログラムの貼り直しやデプロイのやり直しは要りません）。**

1. 送りたい資料の PDF を、Google ドライブ（rivia.co0122@gmail.com）にアップロードする
   - ドライブを開き、左上の「＋ 新規」→「ファイルのアップロード」で PDF を選ぶ
   - 大きさは **20MB まで** にしてください（それより大きいと添付されません）
   - **共有の設定は不要です。**「自分のみ」のままで大丈夫です（プログラムがあなたの権限で読み、メールに添付します）
2. アップロードした PDF を開き（ダブルクリック）、右上の「︙」→「新しいウィンドウで開く」を押す。ブラウザの上のアドレス欄に、次のような URL が出ます
   - `https://drive.google.com/file/d/1AbCdEfGhIjKlMnOpQrStUvWxYz/view`
   - この URL の **`/d/` と `/view` の間の文字列**（例では `1AbCdEfGhIjKlMnOpQrStUvWxYz`）が「ファイルID」です。コピーしておきます
   - 「︙」→「共有」→「リンクをコピー」で取った URL でも、同じ場所にファイルIDがあります
3. https://script.google.com/ で「RIVIA お問い合わせフォーム」のプロジェクトを開く
4. 左側の歯車マーク ⚙ **「プロジェクトの設定」** を押し、いちばん下の **「スクリプト プロパティ」** の **「スクリプト プロパティを追加」**（すでにある場合は「スクリプト プロパティを編集」）を押す
5. 次のように入れて **「スクリプト プロパティを保存」** を押す
   - プロパティ：`DOC_FILE_ID`（半角の大文字。この通りに入れる）
   - 値：手順2でコピーしたファイルID
   - `FOLDER_ID`・`SHEET_ID` という行がすでにある場合は、消さずにそのままにしてください（フォルダとスプレッドシートの場所です）
6. 確かめる：左の「エディタ」（`< >` のマーク）に戻り、関数の選択欄で **`setup`** を選んで「▷ 実行」→ 実行ログに「資料（DOC_FILE_ID）: 「（ファイル名）」（○MB）を添付します」と出れば完了です
   - 「読み込めません」と出たら、ファイルIDのコピー漏れ（前後の空白や `/view` の混入）や、ファイルをゴミ箱に入れていないかを確かめてください
   - 最後に、サイトのフォームから「サービス資料の請求」を選んでテスト送信し、自分宛ての自動返信に PDF が付いているかを見てください

> **資料が設定されていないとき・読み込めないとき**：お客様には添付なしで「資料は担当者より追ってお送りします」というお礼メールが届き、社内通知メールに「資料の添付に失敗（DOC_FILE_ID 未設定など）」という1行が入ります。その場合は、通知メールに返信する形で資料を手動で送ってください。

## 6. メールマガジンの受け取りの同意について

お問い合わせフォーム（RIVIA&CO.・アキヤド）には、「RIVIA&CO.からのお知らせ（空き家活用・民泊のメールマガジン）を受け取る」という任意のチェック欄があります（最初はチェックなしで、お客様が自分でチェックした場合だけ同意になります）。同意した方は、スプレッドシートの右端の「メルマガ」列に「希望する」と記録されます。

- いまは記録するだけで、メールマガジンの配信はしません（今後、配信サービスにつなぐ予定です）
- 以前からあるスプレッドシートには、次のお問い合わせが届いたとき（または `setup` を実行したとき）に、見出しの右端へ「メルマガ」列が自動で足されます。それまでの行は空欄のままです
- 配信をはじめるときは、配信停止の方法をメールに必ず書いてください（特定電子メール法）

## あとから変えたいとき

| やりたいこと | 方法 |
|---|---|
| 自動返信の文面を変えたい | Claude に「自動返信の文面を〇〇に変えて」と伝える（プログラムを直すので、手順の「1.」の貼り付けと「デプロイ」→「デプロイを管理」→ 鉛筆マーク → バージョン「新バージョン」→「デプロイ」をやり直す。URL は変わりません） |
| 通知先を増やしたい | 同じく Claude に伝える（例：共同創業者のアドレスも追加） |
| お問い合わせの一覧を見たい | Google ドライブの「RIVIA_お問い合わせ一覧」を開く |
| 資料請求に送る資料を差し替えたい | 上の「5.」の手順で、新しい PDF のファイルIDを `DOC_FILE_ID` に保存し直す（プログラムの貼り直し不要） |

## よくある質問

| 質問 | 答え |
|---|---|
| お金はかかる？ | かかりません。Gmail から送れるメールは1日100通ほどが上限ですが、いまの規模なら十分です |
| 「このアプリは確認されていません」が怖い | Google の審査を受けていない、自分用のプログラムに必ず出る表示です。あなたのアカウントの中だけで動き、外部にデータを送りません |
| 自動返信が迷惑メールに入ることはある？ | Gmail から送るので届きやすいですが、相手の環境によっては入ることがあります。そのため、送信完了ページに「迷惑メールフォルダもご確認ください」の案内を残しています |
| Formspree はどうなる？ | 使わなくなります。切り替えが済んだら、Formspree のアカウントは解約（削除）して大丈夫です |
