# GitHub と Vercel をはじめて使う人のための手順書

AI社員チームが作った変更を、**確認して公開する**ための手順です。パソコンへのインストールやコマンドの入力は一切ありません。ブラウザ（またはスマホの GitHub アプリ）だけで完結します。

---

## 0. 言葉の説明（これだけ覚えれば大丈夫）

| 言葉 | 意味 |
|---|---|
| **GitHub（ギットハブ）** | サイトのファイル一式を保管している場所。いわば「サイトの原本が入った共有フォルダ」 |
| **リポジトリ** | その共有フォルダ1つ分のこと。このサイトは `riviaco0122-cyber/hp` |
| **ブランチ** | 原本を壊さずに作業するための「コピー」。AI社員チームはコピーの上で作業する |
| **本番ブランチ** | 実際にサイトに出ている原本。いまの名前は `claude/google-drive-file-refresh-rnv3qr` |
| **PR（プルリクエスト）** | 「コピーで作業した変更を、原本に反映していいですか？」という **確認依頼書** |
| **マージ** | 確認依頼書を承認して、変更を原本に反映すること。**＝公開ボタン** |
| **Vercel（バーセル）** | GitHub の原本を見て、自動でサイトを公開してくれるサービス |
| **プレビュー** | マージする前に「公開したらこう見える」を確認できる仮のサイト。Vercel が PR ごとに自動で作る |

全体の流れ:
```
毎朝9時 AI社員チームが作業 → PR（確認依頼書）ができる → Gmail に通知
  → あなたが PR とプレビューを見る → 問題なければ「Merge」を押す → Vercel が自動で公開（数分）
```

---

## 1. 最初に1回だけやること

### 1-1. GitHub にログインできるようにする
1. ブラウザで https://github.com を開き、右上の「Sign in」からログインする
   - リポジトリの持ち主のアカウント `riviaco0122-cyber` でログインできるか、まず試す（メールアドレスが rivia.co0122@gmail.com のアカウントの可能性が高い）
   - パスワードが分からないときは「Forgot password?」から再設定できる
   - **このアカウントが共同創業者の方のものだった場合**は、自分の GitHub アカウントを無料で作り（「Sign up」）、共同創業者の方に「コラボレーターとして招待」してもらう（`docs/request-to-cofounder.md` の 3）
2. スマホでも確認したい場合は、App Store / Google Play で「GitHub」アプリを入れて同じアカウントでログインする

### 1-2. 通知が Gmail に届くようにする
- AI社員チームの毎朝の作業が終わると、**Claude から作業結果のメール**が届くように設定します（Claude 側で設定。あなたの作業は不要）
- あわせて GitHub からも、PR ができたとき・更新されたときにメールが届きます。届かない場合は:
  1. https://github.com/riviaco0122-cyber/hp を開く
  2. 右上の「👁 Watch」→「All Activity」を選ぶ
  3. 右上の自分のアイコン → Settings → Notifications で「Email」にチェックが入っているか確認する

## 2. 毎回の確認と公開の手順（10分ほど）

### 2-1. PR を開く
1. 届いたメールのリンクを押す。または https://github.com/riviaco0122-cyber/hp/pulls を開く
2. 一覧から「SEO/AIO 改善（日付〜）」という名前の PR を開く

### 2-2. 説明文を読む（いちばん大事）
PR を開いて最初に見える文章が、AI社員チームからの報告書です。特に次の欄を読みます。
- **変更したこと**：今回やったことの一覧
- **人の確認が必要な点**：法律・税金・数字など、あなたに見てほしいところ
- **監修の対象になる記事**：あなたがマージすることが「監修の確認」になる記事と、特に読んでほしい箇所
- **品質管理部の採点結果**：記事ごとの点数（95点以上のものだけが入っている）

### 2-3. プレビューで見た目を確認する
1. PR のページを下にスクロールすると、**Vercel（▲のマーク）からのコメント**があります
2. その中の「Preview」または「Visit Preview」のリンクを押すと、**公開後とまったく同じサイト**が開きます（まだ公開されていません）
3. 説明文の「プレビューで見てほしいページ」を開いて、文章と見た目を確認します。スマホでも開けます
   - Vercel のログイン画面が出て見られない場合は、共同創業者の方に設定を頼みます（`docs/request-to-cofounder.md` の 2-3）

### 2-4. 直してほしいところがあったら
- PR のいちばん下のコメント欄に、日本語でそのまま書いて「Comment」を押す（例:「〇〇の記事の『△△』という表現をやわらかくしてほしい」）
- または、Claude のチャットで「PR の〇〇を直して」と伝える
- 直ったら、もう一度 2-2 から確認します

### 2-5. 問題がなければ公開（マージ）
1. PR のページの下のほうにある緑のボタン **「Merge pull request」** を押す
2. 続けて出てくる **「Confirm merge」** を押す
3. 紫色の「Merged」という表示になれば完了。**数分後にサイトに反映されます**
   - 反映されたかは https://rivia-co.com を開いて確認（古い表示のときは、ページの再読み込み）

> マージしない限り、何も公開されません。忙しい日は何もしなくて大丈夫です。翌日以降の作業は、同じ PR に追加されていきます（週1〜2回まとめての確認がおすすめ）。5日以上マージされないと、AI社員チームは新しい記事を作らずに待ちます。

---

## 3. 困ったとき

| 状況 | どうするか |
|---|---|
| 緑の「Merge」ボタンが押せない（灰色） | 画面の表示（「conflicts」など）をスクリーンショットして、Claude に送る |
| マージしたのにサイトが変わらない | 10分待ってから再読み込み。それでも変わらなければ、共同創業者の方に Vercel の「Deployments」を見てもらう |
| 公開した内容を元に戻したい | Claude に「さっき公開した〇〇を元に戻して」と伝える（戻すための PR を作ります） |
| よく分からない表示が出た | スクリーンショットを Claude に送る |
