# 共同創業者への依頼書（サイト更新の流れの切り替え）

> この文書は、そのまま共同創業者の方に送れるように書いています。「依頼のメッセージ」をコピーして、LINE やメールで送ってください。所要時間は全部で15〜30分ほどです。

---

## 依頼のメッセージ（コピー用）

```
お疲れさま。サイト（rivia-co.com）の更新方法を変えたいので、少し作業をお願いしたいです。

これまで「Claude でファイル生成 → Drive に格納 → あなたの PC から GitHub・Vercel に反映」してもらっていたけど、
今後は Claude（AI社員チーム）が GitHub 上で直接ファイルを直して、私が GitHub でマージすると Vercel が自動で公開する流れにします。
あなたの PC での反映作業は不要になります。

そのために、次の3つをお願いできますか？（手順は下にまとめています）
1. Drive 経由での反映を止める（いま作業中のものがあれば、その分だけ反映してから止める）
2. Vercel の設定を確認する（GitHub と自動でつながっているか、プレビューを私が見られるか）
3. 必要なら、GitHub と Vercel に私を招待する

終わったら、各手順の画面のスクリーンショットを送ってもらえると助かります。
```

## 1. Drive 経由での反映を止める

1. いま Drive に格納していて、まだ反映していないファイルがあるかを確認する
   - **ある場合**: いつもどおりその分だけ反映し、反映が終わったことを連絡する（AI社員チームはその変更を取り込んでから作業します）
   - **ない場合**: 何もしなくてよい
2. 以降は、Drive からの反映（GitHub への push、Vercel CLI での手動デプロイなど）をしない
   - 理由: AI社員チームの変更と、Drive からの変更がぶつかり、どちらかが上書きされて消えるため
   - サイトを直したいときは、Claude のチャットで頼めば PR として作られる

---

## 2. Vercel の設定を確認する

### 2-1. Vercel にログインしてプロジェクトを開く
1. https://vercel.com にログインする（いつも反映に使っているアカウント）
2. ダッシュボードから rivia-co.com のプロジェクトを開く

### 2-2. GitHub とつながっているか（自動公開の設定）
1. プロジェクトの画面で上のメニューの **「Settings」** → 左のメニューの **「Git」** を開く
2. **Connected Git Repository** に `riviaco0122-cyber/hp` と表示されているか確認する
   - **表示されていない場合**: 「Connect Git Repository」→「GitHub」を選び、`riviaco0122-cyber/hp` を選んで接続する（GitHub へのアクセス許可を求められたら許可する）
3. 同じ画面（または Settings → Environments → Production）の **Production Branch** が `claude/google-drive-file-refresh-rnv3qr` になっているか確認する
   - 違う場合は、その名前に変更して保存する
   - ※ いま GitHub のデフォルトブランチ（本番の原本）がこの名前のため
4. この画面のスクリーンショットを送る

### 2-3. PR のプレビューを見られるようにする
PR ごとに作られるプレビューのサイトは、初期設定では **Vercel にログインしているチームメンバーしか見られない** ことがあります（Deployment Protection）。
1. Settings → 左のメニューの **「Deployment Protection」** を開く
2. **「Vercel Authentication」** が有効（Enabled / Standard Protection）になっているか確認する
3. 有効になっている場合は、次のどちらかにする
   - **A（おすすめ・無料）**: Vercel Authentication を **無効（Disabled）** にして保存する
     - プレビューの URL は推測できない長い文字列なので、URL を知っている人しか見られない
     - 本番サイト（rivia-co.com）には影響しない
   - **B**: チームに招待する（Settings → Members）。ただし Vercel の無料プラン（Hobby）ではメンバーを追加できないため、有料プラン（Pro）が必要
4. 設定後の画面のスクリーンショットを送る

## 3. GitHub の権限の確認（必要な場合だけ）

GitHub のアカウント `riviaco0122-cyber` に、依頼者（私）が自分でログインできるなら、この手順は不要です。ログインできない場合だけお願いします。

1. https://github.com/riviaco0122-cyber/hp を開く（リポジトリの持ち主のアカウントでログイン）
2. 上のメニューの **「Settings」** → 左のメニューの **「Collaborators」** を開く
3. **「Add people」** を押し、私の GitHub のユーザー名かメールアドレスを入れて招待する
4. 私に届く招待メールの「Accept invitation」を押してもらえば完了
