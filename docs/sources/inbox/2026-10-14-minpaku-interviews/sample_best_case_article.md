# 空き家を旅館業で民泊に｜初期費用400万円・月の純利益25万円、失敗3つまで公開した事例

築45年の空き家を、旅館業（簡易宿所）の許可を取って宿にしたFさん。初期費用は約400万円、運営14ヶ月目の月の純利益は平均約25万円です。冬の閑散期は約8万円、夏の繁忙期は約40万円と、月による差は大きくなります。自己資金150万円は、運営開始から約半年で回収できる計算です。一方で、消防設備の費用が想定の約1.5倍になるなど、想定外も3つありました。費用の内訳、毎月の収支、許可取得の流れ、失敗と対処を、本人の言葉と数字で整理します。

## この事例の結論

- 初期費用は約400万円。最も大きいのは建物の改修（約220万円）で、全体の半分以上を占めた。
- 月の純利益は平均約25万円。冬の閑散期は約8万円、夏の繁忙期は約40万円で、季節差は5倍になる。
- 許可取得は、事前相談から営業開始まで約6ヶ月。想定外は、消防設備の費用、開業直後の低稼働、冬の光熱費の3つ。

## 空き家を民泊にする初期費用はいくら？総額約400万円の内訳

| 項目 | 金額 | 内容 |
|---|---|---|
| 建物の改修 | 約220万円 | 水回り・内装 |
| 消防設備 | 約60万円 | 自動火災報知設備・誘導灯など |
| 図面作成・許可申請 | 約25万円 | 各種書類・手続き |
| 家具・家電・備品 | 約70万円 | 寝具・キッチン用品を含む |
| 開業準備 | 約25万円 | 写真撮影・掲載準備・運転資金 |
| **合計** | **約400万円** | |

改修費が全体の半分以上を占めたのは、築45年で水回りの傷みが大きかったためです。キッチン・浴室・トイレの入れ替えに加えて、床と壁の補修が必要でした。一方、家具は新品にこだわらず、必要なものから買い足す形で費用を抑えています。

**Fさん：** 「最初は250万円くらいで収まると思っていました。見積もりを取ってみたら、水回りだけで予算の半分近くになって、正直焦りました」

資金は、自己資金150万円と、日本政策金融公庫の創業融資250万円で用意しました。返済は月約3万円で、期間は約8年です。予算を立てるときは、見積もりの1〜2割を予備費として見込んでおくと、想定外の出費に慌てずに済みます。

## 月の収支はいくら？平均の純利益は約25万円、冬は約8万円

冬でも赤字にはなりませんでしたが、月による差は大きくなります。月商が下がっても、返済や固定資産税などの固定費は変わらないため、閑散期は利益が大きく減ります。計画を立てるときは、平均だけでなく、最も悪い月でも続けられるかを確認してください。自己資金の150万円は、平均の純利益約25万円で割ると約6ヶ月分です。季節の波を考えると、回収には半年から1年弱の幅を見ておくと安全です。

## 旅館業の許可はどう取った？相談から営業開始まで約6ヶ月

1. **事前相談（約1ヶ月）。** 保健所・消防署・建築の窓口に、改修の前に相談します。
2. **図面作成と改修の設計（約1ヶ月）。** 相談で分かった基準に合わせて、設計します。
3. **改修と消防設備の工事（約3ヶ月）。**
4. **消防署の検査、保健所への申請と施設検査（約1ヶ月）。** 許可が出て、営業を開始します。

**Fさん：** 「一番大事だったのは、最初の事前相談です。工事を始める前に基準を聞けたので、やり直しにならずに済みました」

手続きの順序や必要書類は自治体で異なります。事前相談が、最も重要な工程です。

## うまくいかなかったこと3つと、その対処

**1. 消防設備の費用が、想定の約1.5倍になった。** 想定は約40万円でしたが、実際は約60万円でした。対処として、設計の前に消防署へ相談し、複数の業者から見積もりを取るようにしました。

**2. 最初の2ヶ月は、稼働が約40%にとどまった。** 写真を撮り直し、説明文を見直して改善しました。最初の数件のレビューを集めることを、優先しています。

**3. 冬の光熱費が、想定以上にかかった。** 閑散期は、最低宿泊数と価格を調整して、負担を抑えています。

## よくある質問

**空き家を民泊にするには、総額いくらかかりますか？**
この事例では約400万円でした。物件の状態や規模、設備で大きく変わるため、改修の前に見積もりを取ります。

**旅館業の許可は、誰でも取れますか？**
建築・消防・保健衛生の基準を満たし、用途地域で営業が認められる必要があります。物件によっては取得が難しいため、改修の前に、保健所・消防署・建築の窓口へ事前相談します。

**会社員でも、公庫の創業融資を借りられますか？**
この事例では借りられました。審査では、事業計画書と自己資金が見られます。要件は制度ごとに変わるため、公庫の最新情報で確認してください。

**旅館業の民泊には、年間の営業日数の上限はありますか？**
旅館業の許可を取った施設には、住宅宿泊事業法（民泊新法）のような年180日の上限はありません。ただし、地域の条例や用途地域の制限があるため、事前相談で確認します。

**運営は自分でやるのですか？**
この事例では、清掃を委託し、予約対応と価格調整を自分で行っています。週に数時間の対応で回っています。
