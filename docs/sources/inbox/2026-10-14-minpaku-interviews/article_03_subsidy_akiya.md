# 空き家を買って民泊に｜補助金150万円＋公庫融資200万円で改装、月の純利益15〜18万円の事例

通い詰めた港町で、地元の食堂のお母さんから「空き家になる家を、誰か使ってくれない？」と相談されたCさん。都内で働く会社員のCさんは、維持費の計算を重ねたうえで家を引き取り、市の補助金と日本政策金融公庫の融資を組み合わせて、民泊として再生しました。改装の総額は約450万円、運営開始後の月商は約45万円、月の純利益は15万〜18万円です。資金の組み立て方を中心に、うまくいった理由と注意点を整理します。

## この事例の結論

- 自己資金は100万円が限界でも、補助金150万円と公庫融資200万円を組み合わせて、総額約450万円の改装予算をつくった。
- 安全に関わる工事（雨漏り・水回り・消防設備）は地元の職人に任せ、ペンキ塗りや家具選びは自分で行った。
- 月商は約45万円、公庫の返済は月約3.5万円。それを含む経費を引いた純利益は、月15万〜18万円（繁忙期は約20万円）。

## 事例の概要（取材時期：2025年9月〜12月）

| 項目 | 内容 |
|---|---|
| 営業形態 | 旅館業許可を取得し、通年営業 |
| 取材対象 | Cさん（都内のIT企業に勤める会社員） |
| 物件 | 購入した高台の空き家（古民家）。海を一望できる |
| 資金の内訳 | 自己資金100万円＋補助金150万円＋公庫融資200万円＝総額約450万円 |
| 客層 | 女性の一人旅、カップル |

## 費用と収支はいくら？総額約450万円、純利益は月15万〜18万円

**初期費用（改装予算）の内訳**

| 資金源 | 金額 | 備考 |
|---|---|---|
| 自己資金 | 100万円 | 貯金から出せる限界の額 |
| 補助金（市の空き家活用・地域活性化補助金） | 150万円 | 制度は「改修費の半額（上限200万円）」 |
| 公庫の創業融資 | 200万円 | 返済は月約3.5万円 |
| **合計** | **約450万円** | |

**月の収支**

| 項目 | 金額 |
|---|---|
| 月商 | 約45万円 |
| 公庫の返済 | 月約3.5万円 |
| 純利益 | 15万〜18万円（繁忙期は約20万円） |

純利益は、公庫の返済、OTA手数料、光熱費、清掃委託費などをすべて引いた後の金額です。

自己資金の100万円は、月の純利益15万〜18万円の約6〜7ヶ月分です。

## 通っていた町で、空き家の相談を受けた：きっかけ

**── 最初に、この宿を始めたきっかけから教えてください。**

**Cさん：** いつも行く食堂のお母さんから、「知り合いのおじいちゃんが施設に入ることになって、高台にある家が空き家になっちゃうんだよね。解体するにもお金がかかるし、親族も遠方にいて困っていて……誰か使ってくれる人知らない？」って相談を受けたんです。

**── ご相談を受ける前から、この町とは縁があったのですか？**

**Cさん：** 私は都内のIT企業で事務職をしている、普通の会社員です。もともと旅が好きで、特にこの港町が好きで、年に何度も一人旅で通い詰めていました。高台からの海景色も素晴らしいうえに、地元の方々がいつも「お姉ちゃん、また来たの？」と温かく迎えてくれて、私にとって大切なリフレッシュの場所だったんです。

**── 実際にその家を見て、どう感じましたか？**

**Cさん：** 案内してもらうと、古いけれど縁側から海が一望できる、本当に素敵なお家でした。ロケーションに一目惚れしたものの、「普通の会社員である私が家を買うなんて現実味がない」と、何日も真剣に悩みました。

## 購入はどう決めた？維持費と売上のシミュレーション

**── どのように購入を決断したのですか？**

**Cさん：** 格安で譲っていただけるお話ではあったのですが、購入後の固定資産税や草むしりなどの維持費が毎月かかってきます。そこで、「普段は自分が使わない期間をゲストに貸し出す民泊にして、その売上で維持費やローンをカバーできれば、自分も大好きな町に拠点が持てるし、家も守れるんじゃないか」とシミュレーションを重ねたんです。これならリスクを抑えて挑戦できると確信し、思い切って引き取る決断をしました。

購入の前に、維持費と民泊の売上を見比べて「カバーできるか」を確認したのが、決め手です。

## 補助金と公庫融資はどう組み合わせた？

**── 古民家の改修には費用がかかったのではないですか？**

**Cさん：** まさにそこが一番の課題でした。家を安く譲っていただけたとはいえ、長年住んでいた家なので、雨漏りの修繕や水回りの刷新が必要でした。でも、私の少ない貯金から出せる自己資金は100万円くらいが限界で、とてもプロの業者さんにフルリフォームを頼める金額ではありませんでした。

**── どう解決したのですか？**

**Cさん：** 困り果てて、市役所の移住・空き家相談窓口に足を運びました。そうしたら、担当者の方がすごく親身になってくださって、「市で実施している『空き家活用・地域活性化補助金』を使えば、改修費の半額（上限200万円）が出ますよ」と教えてくれたんです。足りない部分は、日本政策金融公庫の小規模な創業融資（200万円）を申請して、なんとか総額約450万円（自己資金100万＋補助金上限150万＋公庫融資200万）の改装予算を確保できました。雨漏りの修理や水回り（お風呂・トイレ）、消防設備の工事といった安全に関わる部分は地元の職人さんにお任せして、私はペンキ塗りや家具の買い出しなどを担当しました。

## 豪華さではなく「居心地」で勝負した宿づくり

**── 内装は、どんなコンセプトにしたのですか？**

**Cさん：** 高級ホテルのような豪華な設備は作れませんが、何度も一人旅でこの町に通う中で、「こんな宿があったらいいな」と思っていた要素を詰め込みました。縁側から海が見える特等席に、心地よいソファを置いて、大好きな本やハーブティー、アロマを用意しました。「都会の喧騒から離れて、静かに自分を取り戻せる場所」というテーマで、空間を作ったんです。

**── 集客や収支はいかがですか？**

**Cさん：** 女性一人旅やカップル層に口コミで人気が広がり、月商は約45万円を維持しています。公庫の毎月約3.5万円の返済に加え、OTA手数料、光熱費、清掃委託費などをすべて引くと、毎月15万〜18万円ほどの純利益（繁忙期には約20万円）が手元に残る状態です。補助金で初期投資を抑えられたため、堅実に手元資金を蓄えつつ、大好きな町で無理なく続けられています。

## うまくいかなかったこと：取材でわかった「最初の壁」

1. **自己資金が少なかった。** 貯金から出せるのは100万円ほどで、フルリフォームは頼めませんでした。補助金と公庫融資を組み合わせて、不足を埋めました。
2. **古い家の修繕が必要だった。** 雨漏りの修繕や水回りの刷新が必要で、安全に関わる部分は職人さんに依頼しました。
3. **購入の決断に時間がかかった。** 「普通の会社員が家を買う」ことの現実味が持てず、何日も悩みました。維持費と売上のシミュレーションで、決断につなげています。

## 解説：補助金と公庫融資を組み合わせるときの注意点

- 補助金は、申請や交付決定の前に工事に着手すると対象外になる場合があります。着工の前に、自治体の窓口で条件を確認します。
- 多くの補助金は、工事完了後の精算払いです。入金までの資金をどう手当てするかを、計画に入れておきます。
- 公庫の創業融資では、事業計画書と自己資金の状況が見られます。補助金の見込みも計画に反映します。
- 民泊（宿泊施設）が補助の対象になるかは、自治体ごとに異なります。

## 空き家を民泊にする前の確認リスト

- [ ] 維持費と、民泊の売上見込みを比べるシミュレーションを作ったか
- [ ] 自治体の移住・空き家の相談窓口で、使える補助金を確認したか
- [ ] 補助金の対象経費・上限・交付の時期（先払いか後払いか）を確認したか
- [ ] 公庫の創業融資に必要な書類（事業計画書など）を把握しているか
- [ ] 安全に関わる工事（雨漏り、水回り、消防設備）を、専門業者に頼む前提で見積もったか

## よくある質問

**補助金は、改修費のどれくらいが出ますか？**
この事例で使った市の制度は、「改修費の半額（上限200万円）」でした。Cさんが受け取った補助金は150万円です。対象経費の範囲や上限は、自治体ごとに異なります。

**会社員でも、公庫の創業融資を借りられますか？**
この事例では、都内のIT企業に勤めるCさんが借りています。審査では、事業計画書や自己資金の状況が見られます。要件は変わるため、公庫の最新情報で確認してください。

**空き家は買うのと借りるのと、どちらがよいですか？**
Cさんは、格安で譲ってもらう形で購入しました。購入すると固定資産税などの維持費がかかるため、民泊の売上でカバーできるかを先に試算しています。

**運営は自分でやるのですか？**
Cさんは、清掃を委託しています。月に1〜2回は自分も泊まり、リモートワークや読書をしているといいます。

## これから空き家活用を考える人へ：Cさんからのメッセージ

**Cさん：** 最初の「維持費どうしよう……」という不安は完全に消えて、本業以外の堅実な収入の柱ができました。始める前に、次の3つを確認してみてください。

1. **維持費と売上のシミュレーションを先に作る。** 私は固定資産税や草むしりの費用を、民泊の売上でカバーできるかを計算してから購入を決めました。
2. **まず自治体の窓口に相談する。** 私は市役所の移住・空き家相談窓口で補助金のことを教わり、改修費の見通しが立ちました。
3. **安全に関わる工事は職人さんに任せ、自分は内装に集中する。** 雨漏りや水回り、消防設備はプロに、ペンキ塗りや家具選びは自分で担当しました。

月に1〜2回は自分もこの家に泊まって、静かに海を眺めながらリモートワークをしたり読書をしたりしています。地域の人たちともさらに深い繋がりができて、「お帰り！」って言ってもらえる第2の故郷になりました。
