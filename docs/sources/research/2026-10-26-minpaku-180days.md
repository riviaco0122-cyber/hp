### 2-1 住宅宿泊事業法（e-Gov API 取得分 /tmp/akiyado-pages/laws.e-gov.go.jp_api_1_lawdata_429AC0000000065.txt。本文照合済み）
| 条 | 内容（要約） | 記事での使い方 |
|---|---|---|
| 第2条（定義） | 住宅宿泊事業＝旅館業の営業者以外の者が宿泊料を受けて住宅に人を宿泊させる事業で、**国交省令・厚労省令で定めるところにより算定した日数が一年間で百八十日を超えないもの** | 180日の根拠。「数え方は省令で決まる」と明記できる |
| 第3条第1項 | 都道府県知事等に届出をした者は、旅館業法第3条第1項にかかわらず事業を営める | 届出が180日以内の営業の入口 |
| 第14条 | 宿泊させた日数などを、省令の定めにより**定期的に都道府県知事に報告**しなければならない | 日数は自己申告＋報告で見られる |
| 第76条第3号 | 第14条の報告をせず、又は虚偽の報告をした者は**30万円以下の罰金** | 数字の誤魔化しは罰金の対象 |
| 第17条 | 都道府県知事は、報告を求め、職員に届出住宅へ立入検査・質問をさせることができる | 日数のチェックの手段 |
| 第15条・第16条 | 業務改善命令／違反時は1年以内の業務停止、さらに廃止命令 | 超過後の行政処分の流れ |
| 第73条第2号 | 第16条の命令に違反した者は6月以下の拘禁刑若しくは100万円以下の罰金（併科あり） | 命令を無視した場合 |
| 第18条 | 都道府県等は、生活環境の悪化を防ぐため必要があるとき、政令の基準に従い**条例で区域を定め、実施する期間を制限できる** | 180日より短くなる根拠 |
| 第78条 | 従業者の違反は行為者を罰するほか、法人・人にも罰金刑 | 法人運営でも対象 |

- **条文上、「180日を超えたこと自体」への直接の罰則条文は、取得分の本文では見つけていない。** 超過の扱いは次の2-3（自治体ページ）で補う。「超えたら罰金◯円」と条文だけで断定しない。
- 第3条第4項（変更届）違反は30万円以下の罰金（第76条第1号）。第3条第6項（廃止の届出）怠りは20万円以下の過料（第79条）。

## 6. 使ってよい RIVIA の体験（experience.md の「人が確認済み」節のみ）
- 3-2（2026-10-11 確認）: 創業メンバーは下田で旅館業法の簡易宿所の許可を取得。**民泊新法の180日の制限を避け、通年営業するため**。保健所と消防署に開業の2か月前に事前相談、自分で申請、申請から許可まで1〜2か月、許可番号がないと Airbnb で予約を受けられない。
- 同節の下田の月別稼働率（1年目平均 約53%）は、「稼働率が約5割でも180日（約49%）の上限に近い」という論点に使える可能性（日数換算は筆者の計算になるので、記事では計算式を示し、「稼働率≒宿泊日数/営業可能日」と断る。事実として書くのは稼働率の値のみ。人の確認推奨）。出典は運営事例記事 `case-rental-house-inn-first-year`。
- 使えない: 180日で届出運営をした体験（なし）。他の運営施設・焼津・竹原の運営数字（開業前・非公表）。
- 書き方の注意: 下田は「創業メンバーが個人事業として」開業。契約形態・プランは非公表。
