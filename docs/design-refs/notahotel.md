# 参考：NOT A HOTEL（notahotel.com）のスマホ版から読み取った型（2026-11-28 観察）

人の方針（2026-11-28）：SANU と NOT A HOTEL を参考に、構成・企画・デザインまで見直す。見た目・ロゴ・文言・写真は写さず、型だけを使う。
スクリーンショットはリポジトリに置かない。必要なら Firecrawl の firecrawl_scrape（screenshot・fullPage・viewport 390×844）で取り直す。

## 型
- 表紙：端までの写真（動画）に、短い2行の宣言だけ。ボタンは右上の「問い合わせ」1つ。
- 思想：暗い地に、大きな文字の2〜3文だけ。最初の数語だけ白、残りは灰色（読む速さで目が止まる）。前後に1画面ほどの何もない空き。
- 一覧（物件）：1件＝画面の幅いっぱいの写真1枚。上に大きな地名と小さな「Designed by …」。カードの枠も説明文もない。写真の連続そのものが一覧。
- 人（クリエイター）・サービス（コンシェルジュ）：画面いっぱいの写真の下側に、小さな英字のラベル・見出し・3行の説明・丸い大きなボタン。1節1写真1行動。
- 代表の言葉：引用＋名前・肩書き＋ボタン。
- フッター：暗い地に、大きめの文字のリンクを縦に並べる（Company／Contact us）。法務のリンクは小さく灰色で下に。

## SANU との違いと使い分け
- NOT A HOTEL は「暗い地・画面いっぱいの写真・言い切り」で格を見せる。SANU は「生成りの地・余白・人の時間」で温かさを見せる。
- RIVIA のコーポレートは「地域・自然・人の温かさ」が軸なので SANU を地に、事業の一覧・実績・人の見せ方に NOT A HOTEL の「1件＝1枚の大きな写真」「1節1写真1行動」を使う。
