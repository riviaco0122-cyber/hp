# 参考：SANU（sa-nu.com）のスマホ版から読み取った型（2026-11-28 観察）

人の方針（2026-11-28）：SANU をアキヤドとコーポレートの「ロールモデル」にする。見た目・ロゴ・文言・写真は写さず、型（考え方）だけを使う。

## 全体
- 地は白と、温かい生成り（ベージュ）の帯を交互に。差し色は朱色1色だけで、使うのは「予約」「資料」の主な行動だけ。
- 余白が大きい。節と節のあいだに、文字のない白い空きを1画面の半分ほど取る。
- 見出しは短い2行（例「自然がもうひとつの／家になる」）。本文は左揃え・行間広め・1段落3行前後。

## 節の型（上から）
1. 表紙：端までの写真1枚＋白文字の短い告知と、細い線の丸いボタン。
2. 思想：見出し2行＋本文2段落だけ。写真なし、余白で見せる。
3. 写真のモザイク：大小の写真を細い白線で組んだ2列（人が火を囲む・森を歩く・台所に立つ・窓辺）。建物より「そこで過ごす時間」。
4. 特徴：番号（01〜04）＋写真＋見出し＋短文のカードを2列×2段。カードの地は薄い灰色、角は丸めない。
5. 一覧（物件）：生成りの地に、写真カード2列。名前は大きめ、数字（価格）は大きく、特徴は細い線のタグ。
6. 資料請求：丸い朱色の大ボタン＋細い線の丸いボタン（第2の行動）。
7. 写真に縦書きの短い詩（「朝、目覚めると窓の外は森。」）を重ねた大きな1枚。
8. 仕組み：番号つきの節ごとに、短い見出し＋2〜3行＋丸い印の図（売却・相続など）。
9. 人：顔写真＋番号＋見出し＋所属の横並びの一覧（連載記事）。
10. 終わり：空の写真に白文字の2行。

## RIVIA / アキヤドに移すときの考え方
- 「建物」より「そこでの時間・人・まち」の写真を主役にする（地方の暮らし・宿の朝・まち歩き）。
- 1つの節に役割は1つ。文字は短く、残りは写真と余白で伝える。
- 主な行動（相談）は1色の丸いボタンに統一し、第2の行動は線のボタン。
- 数字は大きく、注記は小さく（当事者の記録など）。
