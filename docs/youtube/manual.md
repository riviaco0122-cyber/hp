# YouTube 制作マニュアル（アキヤド）

アキヤドの YouTube 動画を作るときの決まりと手順。作りながら学んだことは、その都度ここに書き足す（最後の「学んだこと」）。

- 動画を作るスクリプト: `tools/video/`（使い方は各ファイルの先頭）
- このリポジトリは公開されている。説明欄の下書き・台本に、取引先・個人名・社外秘を書かない（CLAUDE.md 絶対のルール 9）。

## 0. チャンネルの方針（人の方針 2026-10-17）

**民泊戦略家が、民泊・空き家の専門知識を、誰にでもわかりやすく解説するチャンネル。**
人気のビジネス系解説チャンネルのように、「結論がはっきりしていて、わかりやすく、つい最後まで見てしまう」解説を目指す。

- **立ち位置:** 民泊の「戦略家」。自分で宿を運営し、空き家の活用を支援している立場から、仕組み・数字・判断のしかたを教える。
- **チャンネル名（番組名）:** **アキヤド 民泊school**（人の方針 2026-10-17）。オープニングで毎回これを出す（1-2章）。
- **話し手:** アニメの民泊戦略家「**アキ**」（眼鏡・紺のスーツ・オレンジのネクタイ。`make_strategy_ep1.py` の `CAST.aki`）。顔出し・撮影はしない。**本人の声（録音・声のAI化）も使わない**（人の方針 2026-10-17）。声は VOICEVOX の**青山龍星（喜び）**、速さ1.12・抑揚1.2（明るく、テンポよく。人が候補5つから選んだ。暗い声は不可）。聞き手はユウタ（玄野武宏）。
- **チャンネルの見た目:** アイコンは RIVIA のロゴ（`images/logo/logo-square.svg` を 800×800 の PNG にしたもの。丸く切られてもマークが欠けない）。バナーは `python3 tools/video/banner_channel.py 出力.png`（2560×1440。番組名と説明は、スマホでも切れない真ん中 1546×423 に入れる。左右の宿とアキは PC・テレビでだけ見える。`--guide` で切れない範囲の枠つきの確認用）。説明の文言を変えたら作り直して、人が YouTube Studio の「カスタマイズ → ブランディング」で差し替える。チャンネルの説明・キーワード・リンクの文面は `docs/youtube/channel-profile.md`（正本）。
- **見る人:** 民泊・空き家に興味はあるが、専門知識はない人（副業で始めたい人、空き家を持っている人、宿の運営者）。
- **約束:** 難しい言葉を使わない。使うときは、その場で言いかえる。1本で1つの「わかった！」を持ち帰ってもらう。
- **守ること（CLAUDE.md と同じ）:** 数字・制度には出典（説明欄に書く）。RIVIA の体験は `docs/brand/experience.md` の「人が確認済み」の節だけ。断定口調で話しても、事実は盛らない。省庁名を前面に出した「お役所っぽさ」は避けるが、出典は説明欄に正しく書く。

## 1. チャンネルの動画の種類

| 種類 | 役割 | 中身 | スクリプト |
|---|---|---|---|
| **解説（メイン）** | 専門知識を持ち帰ってもらう。検索・おすすめから新しい人を連れてくる | 民泊戦略家アキが1テーマを図解で解説（**8〜10分くらい**。人の方針 2026-10-17） | `make_strategy_ep1.py`（第1回） |

## 1-2. 解説動画の作り方

**型（1本の流れ）**

0. **オープニング（必須。人の方針 2026-10-17）:** **動画の一番最初（0秒）に、約3.5秒**のオープニングを置く（前に何も入れない）。動きは毎回同じ: 緑の幕が左から入る → ロゴ（家のマーク）が出る → 「アキヤド 民泊school」が出て呼び込みの声 → はける。そのあとすぐ、つかみ（結論）に入る。
   - 目的は「**アキヤドの動画だ**」とわかってもらうことだけ。中身は **ロゴ（家のマーク）＋「アキヤド 民泊school」** と、子どもっぽい声の呼び込み「**アキヤド、みんぱくスクール！**」（VOICEVOX:ずんだもん・あまあま）だけ。
   - **その回のタイトルや動画の説明は入れない**（人の方針: 今回の動画の説明はいらない）。注意書き（情報提供が目的、など）は最後の画面に出す。
   - 見た目はブランドの緑の幕に斜めの線、上下にオレンジと黄の帯、きらきら。毎回同じにする（第1回の実装をそのまま使う）。
   - 呼び込みの声は字幕を出さない（スクリプトの `call=`）。クレジットに「VOICEVOX:ずんだもん」を足す。
   - **オープニングのあとは、画面の左上に今回の動画の短いタイトルをずっと出す**（白い丸みのある札にロゴ。例「民泊を資産に入れる5つの理由」。スクリプトの `EP_TITLE`。人の方針 2026-10-17）。終わりの画面では消す。見出し・図と重ならないこと（自動点検で確かめる）。

1. **最初の15秒で結論か、意外な数字。**「結論から言うと、〇〇です」「〇〇の宿の8割は、ここで失敗します」など（数字は出典のあるものだけ）。
2. **今日わかること**を3つ以内で見せる（目次の図）。
3. **理由・仕組みを3つ。** それぞれ「ひとことの結論 → 図解 → 具体例（体験・計算例）」。
4. **よくある失敗・落とし穴**（劇場の話につなげてもよい）。
5. **まとめ**（結論をもう一度、1枚の図で）。
6. 次に見てほしい動画・アキヤドの記事・無料相談。

**話し方**

- 結論が先、理由があと。1文を短く。「つまり」「ポイントは」で区切る。
- 専門用語は、出たときにその場で言いかえる（例: 稼働率＝1か月のうち、何日お客さんが泊まったか）。
- 数字は計算の中身まで見せる（売上 − 経費 = 手元に残るお金、を図で）。
- 断定してよいのは、出典や体験で裏づけのあることだけ。わからないことは「ここは地域によって違う」と言う。

**画面**

- **ブランドカラー（人の方針 2026-10-17）:** アキヤドの緑 `#2e6b47`・濃い緑 `#1f3a2b`・オレンジ `#cf5f37`/`#c95a35`・黄 `#f0b35a`（サイトの `--m-green`・`--m-cta` と同じ）。背景・グラフ・見出し・字幕の帯・終わりの画面をこの色でそろえる（青や紫を主役にしない）。アキのスーツの紺だけは人物の色として残す。
- **各章の頭は大きなタイトルカード**（「理由 ① 分散」など）。章が変わったことがひと目でわかり、画面が空っぽになる時間もなくす。
- **省庁・機関の名前は、画面にもナレーションにも出さない**（人の方針。劇場と同じ。何度も言われているので必ず守る）。「国は2030年に〜」のように言いかえる。出典は説明欄の一番下だけに書く。

- 話している間も、画面が止まらないように図・数字・キーワードを出し続ける（1画面に文字を詰めない）。
- 図は `make_explainer.py` の部品（家・コイン・矢印・グラフ・アイコン・キャラ）を使う。

**テーマの探し方:** `docs/seo/keywords.md`・Search Console の検索語・YouTube の検索候補（`tools/youtube_research.py`）・ネタ箱（`docs/sources/inbox/`）。記事と同じテーマで作り、記事へリンクする。

**テーマ案（人と相談して決める）**

- 民泊は本当に儲かる？ 売上と経費の中身を全部見せます
- 民泊を始めるまでに、実際にかかる時間とお金（準備に約7か月かかった話）
- 空き家は「売る・貸す・宿にする」どれが得？ 決め方は1つだけ
- 民泊新法・旅館業・特区の違いを、5分でわかるように
- 稼働率・単価・レビュー… 宿の売上を決める3つの数字
- 民泊副業の「うまい話」の見分け方（劇場 第1話の解説版）

## 1-3. 伸びる動画の法則（鉄則）

一般によく知られた法則をまとめた。**うちのチャンネルの数字（YouTube アナリティクス）で確かめて、合わないものは直す。** 確かめた結果は7章に書く。

**YouTube が見ている2つの数字**

- **クリック率（インプレッションのクリック率）:** サムネイルとタイトルを見た人のうち、押した人の割合。YouTube ヘルプでは、多くのチャンネル・動画は2〜10%の間とされる。
- **視聴維持（平均視聴時間・平均再生率）:** 押した人が、どれだけ見続けたか。おすすめに出るかどうかは、この2つで大きく決まる。
- どちらか片方だけでは伸びない。**サムネイルで約束したことを、動画の中で必ず果たす**（約束を破ると、すぐ離脱されて逆に伸びなくなる）。

**サムネイル・タイトル**

1. **サムネイルとタイトルは、同じ言葉をくり返さない。** 2つで1つの「気になる」を作る（例: サムネ「詐欺の仕組み」＋タイトル「月100万円の生徒3人、正体わかる？」）。
2. **答えを見たくなる「すき間」を作る。** 伏せ字（●●）、問いかけ、意外な数字、「→結論」。ただし動画の中で必ず答える。
3. **ひと目（0.5秒）でわかる。** 文字は少なく大きく、要素は3つまで（文字・顔・1つの絵）。スマホの小さな表示で確かめる。
4. **顔は感情がわかる表情で。** 驚き・困り・ドヤ顔。
5. タイトルは、検索される言葉を前のほうに入れる（例: 民泊 副業、空き家 活用）。長さは全角30字前後が目安（後ろは切れて見えにくい）。

**最初の30秒（いちばん離脱が多いところ）**

6. **あいさつ・自己紹介から始めない。** 1秒目から本題。結論・意外な事実・事件の瞬間から入る。
7. **「最後まで見る理由」を最初に言う。**（例:「最後に、いちばん大事な見分け方を1つだけ教えます」「この3人の正体、わかるかな？」）。
8. サムネイルで約束したことに、最初の30秒で触れる（「あ、この動画で合ってる」と思ってもらう）。

**途中で飽きさせない**

9. **画面を5〜10秒ごとに変える。** 図・文字・表情・カメラの寄り引き・場面転換。止まった画面が続くと離れる。
10. **答えを少しずつ出す（オープンループ）。**「理由は3つ。3つめがいちばん大事」「これは後で答えます」。
11. 1本で1テーマ。話がそれたら別の動画にする。
12. 中だるみしやすい真ん中に、問いかけ・クイズ・選択肢（A/B）を入れる。
13. 長さは中身で決める。水増ししない（基本姿勢と同じ）。

**終わり方**

14. 「まとめ」が長いと、そこで離脱される。まとめは短く。
15. **次に見る動画を1本だけ、理由つきで勧める**（「この話の続きは、こちらの動画で」）。説明欄・固定コメントにもリンク。終了画面・カードを使うかは人と決める（サービス紹介動画では使わない方針）。

**チャンネル全体**

16. **シリーズ・再生リストにまとめる。** 1本見た人が次も見るように（解説 ⇄ 劇場をつなげる）。
17. **一定のペースで出す**（例: 週1本）。テーマは「見る人が検索していること」と「おすすめで気になること」の両方から選ぶ。
18. **コメントに答える・固定コメントで問いかける。** 次のテーマの材料になる（コメント本文や投稿者名は、リポジトリに書かない）。
19. ショート動画は入口に使う（本編の一番おいしい30〜60秒を切り出し、本編へ誘導）。
20. **出したら数字を見る。** 公開から48時間と7日で、クリック率・平均再生率・視聴維持のグラフ（どこで離れたか）を見て、7章に「次はどうするか」を書く。改善は1回に1つずつ。

## 2. アキヤド劇場の作り方（物語）

人の方針（2026-10-17）:

- **1話完結。次回予告は出さない**（ネタは人があとで考える）。
- **エンタメとして、誰でも楽しめること。** 難しい話は極力抜く。説明は短く、物語と絵で見せる。
- **省庁・公的機関の名前を出さない**（「公式っぽくて萎える」）。注意の呼びかけも、キャラの言葉で。
- 長さは10分以内ならよい（第1話は6分33秒）。
- 民泊あるあるのシリーズ。詐欺はジャンルの1つ（第1話は「民泊副業の詐欺」）。

最後まで見てもらうための型（第1話で固めた）:

1. **冒頭で謎を出す。** 第1話は「この3人の正体は？ ヒントは、ずっと画面の中に。最後まで見て、見抜けるかな？」。ぼんやりした「秘密がある」より、**見ている人が参加できる問い**（間違い探し）にする。
2. **冒頭は、事件の決定的な瞬間から。** 第1話は、カーソルが「契約する」ボタンを押すところ（押す動きをきちんと見せる）。その後「時間を戻して」本編へ。
3. **手がかりを、途中の場面に散らす。** 同じほくろ・同じネックレスを、SNS・YouTube のコメント・インタビューなど複数の場面に。2回目に見て気づけるように。
4. **リアリティは、実際の手口から。** 人の指摘で入れたもの: 旅する自由人ふうの見た目（派手な金持ちにしない）、「いつでも好きなところに行けます」、本人の旅 YouTube を見てから少額の商品を買う流れ、成功者のインタビュー動画、AI で作った背景・人物、上の先生にお金を払う構造。
5. **種明かしは終盤（全体の最後の1分半くらい）に。** そのあとの教訓は15秒ほど（3つまで）。
6. **最後にもう一段のオチ。** 第1話は「ウマイ先生も、上の先生の生徒さんだった（お金は下から上へ）」。
7. 選択肢（A/B）とカウントダウンで、見る人を参加させる場面を中盤に入れる。
8. **セリフと図をそろえる。** 「〇〇先生の言葉」として図に出す言葉は、物語の中で実際に言わせる。数字の設定も筋を通す（月30万円では旅暮らしは無理 → 月100万円）。

キャラクター（`make_explainer.py` の CAST）: ユウタ（owner）、ミナ（staff・宿を運営している友達）、ウマイ先生（umai・旅する自由人ふう）、変装した生徒（umaiA/B/C）、スゴイ先生（sugoi・`make_scam_ep1.py` で定義）。

## 3. 声・音

- 解説動画の配役: 戦略家アキ＝青山龍星（喜び、速さ1.12・抑揚1.2）、聞き手ユウタ＝玄野武宏、オープニングの呼び込み＝ずんだもん（あまあま）。セリフの間は0.32秒（間延びさせない）。
- 声を選ぶときは、同じセリフで候補を3〜5つ作って人に聞いてもらう（`scratch` に mp3 を作って送る）。
- 声は VOICEVOX（`tools/video/voicevox_tts.py`）。**使った声は全員、動画の最後と説明欄に「VOICEVOX:名前」でクレジット**する。
- 第1話の配役: ナレーション＝青山龍星（しっとり）、ユウタ＝玄野武宏、ミナ＝No.7、ウマイ先生＝剣崎雌雄、生徒A＝もち子さん（クレジットは「もち子(cv 明日葉よもぎ)」）、生徒B＝小夜/SAYO、生徒C＝麒ヶ島宗麟、スゴイ先生＝雀松朱司。
- **ひとりの声の高さを変えて別人にするのは不自然**（第1話で失敗）。別の人物には別の声を使う。
- BGM・効果音は `pop_audio.py` で作る（明るいポップ調。暗い・病院っぽい音は避ける）。

## 4. 書き出しと点検

```
python3 tools/video/make_scam_ep1.py 出力.mp4            # 1920×1080（確認用）
python3 tools/video/make_scam_ep1.py 出力.mp4 --hq       # 2560×1440（YouTube に上げる版）
python3 tools/video/make_scam_ep1.py --preview 秒 秒 ...  # 指定した秒のコマだけ PNG に（/tmp/theater_preview）
```

- 依存: Playwright（Chromium）、ffmpeg、VOICEVOX（`voicevox_tts.py` の先頭に準備の手順）。NODE_PATH は Playwright のある場所に。
- 書き出しは10分以上かかる。バックグラウンドで実行し、時間切れ（タイムアウト）を長めにとる。
- **まず自動点検（人の方針 2026-10-17: 長い動画は人手の確認が大変なので、機械で見つけて自分で直す）。** `python3 tools/video/layout_check.py <スクリプト名> --step 0.5` で、0.5秒ごとに次を機械で探す。問題が0件になるまで直してから書き出す（解説動画のスクリプトは、書き出しの前にこれを自動で走らせ、問題があれば止まる）。
  - covered: 文字が、上に重なった図形・文字に隠れている（札がスマホの裏に隠れる、ハンコが本文を隠す など）
  - clash: 文字どうしが重なっている（見出しとカウントダウン、ラベルどうし など）
  - offscreen: 文字が画面の外にはみ出している
  - subtitle: 字幕の帯が、図の文字を隠している
  - 暗い幕（タイトルの手前・場面転換・終わりの画面）でわざと隠している文字、出入りの途中の薄い文字、人物の名札のようなごく小さい文字は数えない。
  - 機械では見えないもの（人物と図形の重なり、カーソルの当たり方、空っぽの画面、話と絵のずれ）は、次の目視で見る。
- **目視の点検は全編を1秒ごとに見る。** ffmpeg で 1 秒 1 コマを抜き出して並べ（コンタクトシート）、次を確かめる:
  - 文字と図・人物の重なり、画面からのはみ出し、スマホ画面の中の文字のはみ出し
  - カーソルや指さしが、押す・指すものに正しく当たっているか（部品を動かしたら行き先も直す）
  - 場面の頭で、画面が空っぽの時間がないか
  - カウントダウンや見出しが重ならないか
- 直したら、その秒だけ `--preview` で確かめてから全編を書き出す。
- 人に見せるときは、スマホで見やすい 1280×720 の軽い版も作って送る（ダウンロード用は高画質版を「添付」で送る）。

## 4-2. リール・ショート（縦長）

- YouTube の横長の動画をそのまま縦にはしない（画面が小さく、字幕も読めない）。**本編のいちばん「へえ」となる45〜60秒を切り出し、縦長（1080×1920）に組み直す**（人の方針 2026-10-17）。
- 形: 上に「アキヤド 民泊school」と、気になる問いの見出し（2行）／中に本編の場面（字幕なし）／下に大きな字幕（名前つき、句読点で改行）。**「フル版は YouTube で」のボタンは置かない**（アプリの説明・関連動画と重なる。人の指摘 2026-10-18）。
- **アプリの文字・ボタンと重ねない（安全な範囲）**: 各アプリは動画の上に文字やボタンを重ねる。下の約480px（チャンネル名・説明・関連動画・キャプション）、右の約160px（y 880〜1440。いいね・コメントなど）、上の約200px（再生ボタン類）には何も置かない。字幕の箱は下1430まで（行が多いと自動で字を小さくする。**字幕は4行まで**が読みやすいので、長いセリフは台本で分ける）。確認は `--preview` のコマに、この範囲を赤で重ねて見る。**よけ方は左右対称に**（字幕の箱・エンディングは x 140〜940 の中央そろえ。片側に寄せると崩れて見える。人の指摘 2026-10-18）。下の空いた所は空っぽに見えないよう、町並みの飾りだけを置く（情報は置かない）。長い行は字を自動で小さくして箱に収める。
- 作り方: `python3 tools/video/make_reel.py <台本スクリプト名> <開始 場面.セリフ> <終了 場面.セリフ> "<見出し1行目\n2行目>" 出力.mp4 --cover <秒>`（`--preview 秒` でコマだけ確認）。表紙の画像（`-cover.jpg`）も一緒にできる。
- **始まり: 1コマ目から、その回の場面で始める**（前の場面の図が消えていく途中から始めない。人の指摘 2026-10-18。スクリプトが自動で、最初の約0.4秒は今回の場面で止めて始める）。
- **終わり: 最後の約3秒はエンディング「続きは本編で」**（ロゴ・「YouTube『アキヤド 民泊school』」・本編のタイトル・▶本編を見る・「プロフィール・概要欄のリンクから」。人の方針 2026-10-18）。
- **数字の注意を切り落とさない**: 実績の数字を出す区間は、「手間・初期投資は入っていない」などの注意のセリフまで入れる（第1回は 2.2〜2.7）。
- **部品どうしを重ねない・近づけない**（人の指摘 2026-10-18「若干重複してる」）: ロゴ・見出し・場面・名前・字幕は、箱どうし 20px 以上あける。`make_reel.py` は書き出しの前に**配置の自動点検**（セリフごとの真ん中と表紙で、重なり・近すぎ・安全な範囲からのはみ出し）を行い、1件でもあれば止まる。0件になるまで配置を直す（台本の字幕が長すぎるときは台本で分ける）。
- 表紙（`--cover`）は、見出しと、いちばん「へえ」となる図（数字・グラフ）が出ている瞬間を選ぶ。
- **表紙はプロフィールの一覧でも切れない配置にする**（人の指摘 2026-10-18）: Instagram のプロフィールの一覧は、縦長の上下を切って 3:4（1080×1440、上下240pxずつ切る）で見せる。表紙（`-cover.jpg`）は動画のコマをそのまま使わず、スクリプトが前景を110px下げて、見出し〜字幕を y 320〜1570 に収めて別に描く。表紙だけ作り直すときは `--cover 秒 --cover-only`。確認は、表紙の y 240〜1680 を切り出して見出しの「アキヤド 民泊school」と問いが欠けていないかを見る。**投稿のときは必ずこの表紙を設定する**（設定しないと、動画の途中のコマが一覧に出て上が切れる）。
- **投稿情報も毎回作る**（`ep<N>-reel-post.txt`）: YouTube ショート（タイトル・説明・**「関連動画」に本編を設定**・子ども向け＝いいえ・改変コンテンツ＝いいえ）、Instagram リール（キャプション・ハッシュタグ・表紙の設定・プロフィールのリンク・音楽は足さない・AI ラベルは不要）、TikTok（キャプション・カバー・AI 生成コンテンツはオフ）。どれも「試運転・手間と初期投資は別」などの数字の注意と、「続きは本編で」を入れる。リンクには utm を付ける（`utm_source=instagram`／`tiktok`、`utm_medium=social`）。プロフィールのリンクは `channel-profile.md` の固定の URL（`utm_campaign=profile`）を使い、投稿ごとに変えない。
- 選び方: 数字が出て、1つの話がそこだけで完結する区間（例: 第1回の「家賃5万円の家 → 営業利益 → 約3倍」）。見出しは答えを伏せた問い（「家賃5万円の家を宿にしたら？」）。
- Instagram のリール・YouTube ショート・TikTok に同じものを使える。説明文に「フル版はプロフィール／概要欄から」とチャンネル名を書く。

## 5. サムネイル

**解説動画のサムネイルは「シリーズの型」で高級感を出す**（人の方針 2026-10-17・人気の解説シリーズを見て）:
  - 左上に「第◯回」、上に白い問いのカード（「なぜ〇〇なのか？」「〇〇の仕組み」。大事な語だけ色を変える）。
  - その下に、作り込んだイラストの場面（宿・コイン・グラフ・飛行機など、テーマの小物を3〜5個）と、戦略家アキが指さす姿。
  - 背景・配色・カードの位置を毎回そろえる（並んだときに「お金をかけたシリーズ」に見える）。
  - 第1回の実例: `tools/video/thumb_strategy_ep1.py`。
- **劇場のサムネイルも同じシリーズの型にそろえる**（人の方針 2026-10-17）: 左上に緑のバッジ「アキヤド劇場 第◯話」、中央に白い問いのカード（例「民泊副業**詐欺**の仕組み／この3人の正体、わかる？」）、その下にその回の舞台（第1話はセミナー会場の舞台と、？マークを付けた生徒さん3人）。ネタバレはしない。実例: `tools/video/thumb_theater_ep1.py`。
- 下の「文字が主役」の型（黄・白・赤の太字）は、シリーズの型が合わない単発の動画で使う。

人の方針（2026-10-17・伸びているチャンネルの例を見て）: **興味を引いてクリックさせる**。次の型で作る。

- **文字が主役。** 画面の6〜7割を太い文字で埋める。3行くらい、1行は短く。
- **色は黄・白・赤。** 太いふちどり（黒・白）と影で、スマホの小さい表示でも読める。いちばん強い言葉だけ赤や黄で大きく。
- **気になる言葉を入れる。** 「〇〇の仕組み」「●●です」（伏せ字）「要注意」「→結論」「本当に必要？」など、答えを見たくなる形。数字（月100万円など）も効く。
- **人物は右側に大きく**（顔のアップ。表情は驚き・困り顔など感情がわかるもの）。
- **ネタバレしない。** 種明かし（第1話なら「全員AI」）はサムネイルに出さない。
- 行間を詰めすぎない（ふちどりが上下の行とくっつくと読みにくい）。
- 1280×720 の PNG（4/3 倍で描いて縮める）。小さく縮めた版（320×180）でも読めるか確かめる。
- 2案作り、YouTube Studio の「テストと比較」で選ぶ。

解説動画のシリーズの型の細かい決まり（人の指摘 2026-10-17）:
- **問いのカードは画面の中央。** 左上に寄せない（「第◯回」・カード・場面がかたよって見える）。「第◯回」は左上に単独で、ブランドの緑の丸いバッジ。
- 場面は左右に広げる（左: 飛行機と宿 → コイン → グラフ → 右: 指さすアキ）。アキの顔がカードに隠れないこと。
- 背景もブランドカラー（淡い緑の街並み）。カードの上辺に緑の帯。


## 6. タイトル・説明欄・アップロード

- **タイトル:** 【アニメ】＋何がわかるか＋気になる問い＋【アキヤド劇場】。例: 【アニメ】民泊副業詐欺の仕組み｜月100万円の生徒3人、正体わかる？【アキヤド劇場】
- **説明欄の型:** あらすじ3〜4行（最後は問いかけ）→ アキヤドのリンク（`utm_source=youtube&utm_medium=video&utm_campaign=<回>`）→ 無料相談のリンク → 教訓（3つ）→「この物語はフィクションです」→ 音声のクレジット → アキヤドについて → ハッシュタグ。
- **物語の動画には目次（チャプター）を入れない**（種明かしに飛ばされて最後まで見られなくなる）。**解説動画には入れる**（見たい理由に飛べるほうが便利で、検索にも出やすい）。時間は台本のタイミング（各章の頭）から作る。
- **解説動画のタイトル:** 結論＋数字＋【民泊戦略】など。例: 民泊は「第3の資産」になる｜資産に入れるべき5つの理由と、失敗しない入れ方
- **解説動画の説明欄:** 何がわかるか2〜3行 → リンク（記事・相談） → 目次 → 要点 → 宿の数字の注記（試運転・手間と初期投資は含まない など） → 投資を勧めるものではない旨 → 出典 → 音声のクレジット。
- 字幕: スクリプトのセリフから SRT を作り、「字幕」→「ファイルをアップロード」→「タイミングあり」。
- 設定: 子ども向け＝いいえ／改変されたコンテンツ（AI）＝いいえ（アニメで、本物と見間違えないため）／有料プロモーション＝なし。
- **高画質版（2560×1440）を上げる。** 1080p で上げると YouTube 側の画質が落ちやすい。公開直後は低画質しか出ないことがあるが、時間をおけば高画質が出る。
- 終了画面・カードは使わない（人の方針）。

- **改善は数字から**（2026-10-18 に接続を確認済み。チャンネル「アキヤド編集部ー地方民泊攻略channel」）:
  - 鍵: 環境「アキヤド」の環境変数 `YT_CLIENT_ID`・`YT_CLIENT_SECRET`・`YT_REFRESH_TOKEN`（登録手順は `docs/seo/analytics-setup.md` 8章）。つながっているかは `python3 tools/youtube_analytics.py check`。
