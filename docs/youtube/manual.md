# YouTube 制作マニュアル（アキヤド）

アキヤドの YouTube 動画を作るときの決まりと手順。作りながら学んだことは、その都度ここに書き足す（最後の「学んだこと」）。

- 動画を作るスクリプト: `tools/video/`（使い方は各ファイルの先頭）
- このリポジトリは公開されている。説明欄の下書き・台本に、取引先・個人名・社外秘を書かない（CLAUDE.md 絶対のルール 9）。

---

## 0. チャンネルの方針（人の方針 2026-10-17）

**民泊戦略家が、民泊・空き家の専門知識を、誰にでもわかりやすく解説するチャンネル。**
人気のビジネス系解説チャンネルのように、「結論がはっきりしていて、わかりやすく、つい最後まで見てしまう」解説を目指す。

- **立ち位置:** 民泊の「戦略家」。自分で宿を運営し、空き家の活用を支援している立場から、仕組み・数字・判断のしかたを教える。
- **話し手:** アニメの「民泊戦略家」キャラ（人の方針 2026-10-17。顔出し・撮影はしない）。今のキャラと同じ絵柄で作り、声は VOICEVOX。サムネイルの右側の顔もこのキャラ（表情違いを用意する）。キャラの見た目・名前・声は、最初の解説動画を作るときに案を出して人と決める。
- **見る人:** 民泊・空き家に興味はあるが、専門知識はない人（副業で始めたい人、空き家を持っている人、宿の運営者）。
- **約束:** 難しい言葉を使わない。使うときは、その場で言いかえる。1本で1つの「わかった！」を持ち帰ってもらう。
- **守ること（CLAUDE.md と同じ）:** 数字・制度には出典（説明欄に書く）。RIVIA の体験は `docs/brand/experience.md` の「人が確認済み」の節だけ。断定口調で話しても、事実は盛らない。省庁名を前面に出した「お役所っぽさ」は避けるが、出典は説明欄に正しく書く。

## 1. チャンネルの動画の種類

| 種類 | 役割 | 中身 | スクリプト |
|---|---|---|---|
| **解説（メイン）** | 専門知識を持ち帰ってもらう。検索・おすすめから新しい人を連れてくる | 民泊戦略家が1テーマを図解で解説（10〜20分） | これから作る |
| **アキヤド劇場（サブ）** | 楽しく見てもらい、チャンネルを好きになってもらう | 民泊あるあるを、かわいいキャラの1話完結の物語で | `make_scam_ep1.py`（第1話） |
| サービス紹介 | 相談につなげる | アキヤドの相談サービスの紹介（サイトにも埋め込み） | `make_explainer.py` |

劇場の回のテーマは、なるべく解説の回とつなげる（例: 劇場「民泊副業詐欺」→ 解説「民泊で本当にいくら稼げるのか」）。説明欄・終わりのひと言で行き来できるようにする。

## 1-2. 解説動画の作り方

**型（1本の流れ）**

1. **最初の15秒で結論か、意外な数字。**「結論から言うと、〇〇です」「〇〇の宿の8割は、ここで失敗します」など（数字は出典のあるものだけ）。
2. **今日わかること**を3つ以内で見せる（目次の図）。
3. **理由・仕組みを3つ。** それぞれ「ひとことの結論 → 図解 → 具体例（体験・計算例）」。
4. **よくある失敗・落とし穴**（劇場の話につなげてもよい）。
5. **まとめ**（結論をもう一度、1枚の図で）。
6. 次に見てほしい動画・アキヤドの記事・無料相談。

**話し方**

- 結論が先、理由があと。1文を短く。「つまり」「ポイントは」で区切る。
- 専門用語は、出たときにその場で言いかえる（例: 稼働率＝1か月のうち、何日お客さんが泊まったか）。
- 数字は計算の中身まで見せる（売上 − 経費 = 手元に残るお金、を図で）。
- 断定してよいのは、出典や体験で裏づけのあることだけ。わからないことは「ここは地域によって違う」と言う。

**画面**

- 話している間も、画面が止まらないように図・数字・キーワードを出し続ける（1画面に文字を詰めない）。
- 図は `make_explainer.py` の部品（家・コイン・矢印・グラフ・アイコン・キャラ）を使う。

**テーマの探し方:** `docs/seo/keywords.md`・Search Console の検索語・YouTube の検索候補（`tools/youtube_research.py`）・ネタ箱（`docs/sources/inbox/`）。記事と同じテーマで作り、記事へリンクする。

**テーマ案（人と相談して決める）**

- 民泊は本当に儲かる？ 売上と経費の中身を全部見せます
- 民泊を始めるまでに、実際にかかる時間とお金（準備に約7か月かかった話）
- 空き家は「売る・貸す・宿にする」どれが得？ 決め方は1つだけ
- 民泊新法・旅館業・特区の違いを、5分でわかるように
- 稼働率・単価・レビュー… 宿の売上を決める3つの数字
- 民泊副業の「うまい話」の見分け方（劇場 第1話の解説版）

## 1-3. 伸びる動画の法則（鉄則）

一般によく知られた法則をまとめた。**うちのチャンネルの数字（YouTube アナリティクス）で確かめて、合わないものは直す。** 確かめた結果は7章に書く。

**YouTube が見ている2つの数字**

- **クリック率（インプレッションのクリック率）:** サムネイルとタイトルを見た人のうち、押した人の割合。YouTube ヘルプでは、多くのチャンネル・動画は2〜10%の間とされる。
- **視聴維持（平均視聴時間・平均再生率）:** 押した人が、どれだけ見続けたか。おすすめに出るかどうかは、この2つで大きく決まる。
- どちらか片方だけでは伸びない。**サムネイルで約束したことを、動画の中で必ず果たす**（約束を破ると、すぐ離脱されて逆に伸びなくなる）。

**サムネイル・タイトル**

1. **サムネイルとタイトルは、同じ言葉をくり返さない。** 2つで1つの「気になる」を作る（例: サムネ「詐欺の仕組み」＋タイトル「月100万円の生徒3人、正体わかる？」）。
2. **答えを見たくなる「すき間」を作る。** 伏せ字（●●）、問いかけ、意外な数字、「→結論」。ただし動画の中で必ず答える。
3. **ひと目（0.5秒）でわかる。** 文字は少なく大きく、要素は3つまで（文字・顔・1つの絵）。スマホの小さな表示で確かめる。
4. **顔は感情がわかる表情で。** 驚き・困り・ドヤ顔。
5. タイトルは、検索される言葉を前のほうに入れる（例: 民泊 副業、空き家 活用）。長さは全角30字前後が目安（後ろは切れて見えにくい）。

**最初の30秒（いちばん離脱が多いところ）**

6. **あいさつ・自己紹介から始めない。** 1秒目から本題。結論・意外な事実・事件の瞬間から入る。
7. **「最後まで見る理由」を最初に言う。**（例:「最後に、いちばん大事な見分け方を1つだけ教えます」「この3人の正体、わかるかな？」）。
8. サムネイルで約束したことに、最初の30秒で触れる（「あ、この動画で合ってる」と思ってもらう）。

**途中で飽きさせない**

9. **画面を5〜10秒ごとに変える。** 図・文字・表情・カメラの寄り引き・場面転換。止まった画面が続くと離れる。
10. **答えを少しずつ出す（オープンループ）。**「理由は3つ。3つめがいちばん大事」「これは後で答えます」。
11. 1本で1テーマ。話がそれたら別の動画にする。
12. 中だるみしやすい真ん中に、問いかけ・クイズ・選択肢（A/B）を入れる。
13. 長さは中身で決める。水増ししない（基本姿勢と同じ）。

**終わり方**

14. 「まとめ」が長いと、そこで離脱される。まとめは短く。
15. **次に見る動画を1本だけ、理由つきで勧める**（「この話の続きは、こちらの動画で」）。説明欄・固定コメントにもリンク。終了画面・カードを使うかは人と決める（サービス紹介動画では使わない方針）。

**チャンネル全体**

16. **シリーズ・再生リストにまとめる。** 1本見た人が次も見るように（解説 ⇄ 劇場をつなげる）。
17. **一定のペースで出す**（例: 週1本）。テーマは「見る人が検索していること」と「おすすめで気になること」の両方から選ぶ。
18. **コメントに答える・固定コメントで問いかける。** 次のテーマの材料になる（コメント本文や投稿者名は、リポジトリに書かない）。
19. ショート動画は入口に使う（本編の一番おいしい30〜60秒を切り出し、本編へ誘導）。
20. **出したら数字を見る。** 公開から48時間と7日で、クリック率・平均再生率・視聴維持のグラフ（どこで離れたか）を見て、7章に「次はどうするか」を書く。改善は1回に1つずつ。

## 2. アキヤド劇場の作り方（物語）

人の方針（2026-10-17）:

- **1話完結。次回予告は出さない**（ネタは人があとで考える）。
- **エンタメとして、誰でも楽しめること。** 難しい話は極力抜く。説明は短く、物語と絵で見せる。
- **省庁・公的機関の名前を出さない**（「公式っぽくて萎える」）。注意の呼びかけも、キャラの言葉で。
- 長さは10分以内ならよい（第1話は6分33秒）。
- 民泊あるあるのシリーズ。詐欺はジャンルの1つ（第1話は「民泊副業の詐欺」）。

最後まで見てもらうための型（第1話で固めた）:

1. **冒頭で謎を出す。** 第1話は「この3人の正体は？ ヒントは、ずっと画面の中に。最後まで見て、見抜けるかな？」。ぼんやりした「秘密がある」より、**見ている人が参加できる問い**（間違い探し）にする。
2. **冒頭は、事件の決定的な瞬間から。** 第1話は、カーソルが「契約する」ボタンを押すところ（押す動きをきちんと見せる）。その後「時間を戻して」本編へ。
3. **手がかりを、途中の場面に散らす。** 同じほくろ・同じネックレスを、SNS・YouTube のコメント・インタビューなど複数の場面に。2回目に見て気づけるように。
4. **リアリティは、実際の手口から。** 人の指摘で入れたもの: 旅する自由人ふうの見た目（派手な金持ちにしない）、「いつでも好きなところに行けます」、本人の旅 YouTube を見てから少額の商品を買う流れ、成功者のインタビュー動画、AI で作った背景・人物、上の先生にお金を払う構造。
5. **種明かしは終盤（全体の最後の1分半くらい）に。** そのあとの教訓は15秒ほど（3つまで）。
6. **最後にもう一段のオチ。** 第1話は「ウマイ先生も、上の先生の生徒さんだった（お金は下から上へ）」。
7. 選択肢（A/B）とカウントダウンで、見る人を参加させる場面を中盤に入れる。
8. **セリフと図をそろえる。** 「〇〇先生の言葉」として図に出す言葉は、物語の中で実際に言わせる。数字の設定も筋を通す（月30万円では旅暮らしは無理 → 月100万円）。

キャラクター（`make_explainer.py` の CAST）: ユウタ（owner）、ミナ（staff・宿を運営している友達）、ウマイ先生（umai・旅する自由人ふう）、変装した生徒（umaiA/B/C）、スゴイ先生（sugoi・`make_scam_ep1.py` で定義）。

## 3. 声・音

- 声は VOICEVOX（`tools/video/voicevox_tts.py`）。**使った声は全員、動画の最後と説明欄に「VOICEVOX:名前」でクレジット**する。
- 第1話の配役: ナレーション＝青山龍星（しっとり）、ユウタ＝玄野武宏、ミナ＝No.7、ウマイ先生＝剣崎雌雄、生徒A＝もち子さん（クレジットは「もち子(cv 明日葉よもぎ)」）、生徒B＝小夜/SAYO、生徒C＝麒ヶ島宗麟、スゴイ先生＝雀松朱司。
- **ひとりの声の高さを変えて別人にするのは不自然**（第1話で失敗）。別の人物には別の声を使う。
- BGM・効果音は `pop_audio.py` で作る（明るいポップ調。暗い・病院っぽい音は避ける）。

## 4. 書き出しと点検

```
python3 tools/video/make_scam_ep1.py 出力.mp4            # 1920×1080（確認用）
python3 tools/video/make_scam_ep1.py 出力.mp4 --hq       # 2560×1440（YouTube に上げる版）
python3 tools/video/make_scam_ep1.py --preview 秒 秒 ...  # 指定した秒のコマだけ PNG に（/tmp/theater_preview）
```

- 依存: Playwright（Chromium）、ffmpeg、VOICEVOX（`voicevox_tts.py` の先頭に準備の手順）。NODE_PATH は Playwright のある場所に。
- 書き出しは10分以上かかる。バックグラウンドで実行し、時間切れ（タイムアウト）を長めにとる。
- **点検は全編を1秒ごとに見る。** ffmpeg で 1 秒 1 コマを抜き出して並べ（コンタクトシート）、次を確かめる:
  - 文字と図・人物の重なり、画面からのはみ出し、スマホ画面の中の文字のはみ出し
  - カーソルや指さしが、押す・指すものに正しく当たっているか（部品を動かしたら行き先も直す）
  - 場面の頭で、画面が空っぽの時間がないか
  - カウントダウンや見出しが重ならないか
- 直したら、その秒だけ `--preview` で確かめてから全編を書き出す。
- 人に見せるときは、スマホで見やすい 1280×720 の軽い版も作って送る（ダウンロード用は高画質版を「添付」で送る）。

## 5. サムネイル

解説動画も劇場も同じ型。解説動画は、**戦略家（話し手）を右側に大きく**、左に結論を伏せた太い文字（例:「民泊は儲かる？→結論●●です」）。

人の方針（2026-10-17・伸びているチャンネルの例を見て）: **興味を引いてクリックさせる**。次の型で作る。

- **文字が主役。** 画面の6〜7割を太い文字で埋める。3行くらい、1行は短く。
- **色は黄・白・赤。** 太いふちどり（黒・白）と影で、スマホの小さい表示でも読める。いちばん強い言葉だけ赤や黄で大きく。
- **気になる言葉を入れる。** 「〇〇の仕組み」「●●です」（伏せ字）「要注意」「→結論」「本当に必要？」など、答えを見たくなる形。数字（月100万円など）も効く。
- **人物は右側に大きく**（顔のアップ。表情は驚き・困り顔など感情がわかるもの）。
- **ネタバレしない。** 種明かし（第1話なら「全員AI」）はサムネイルに出さない。
- 行間を詰めすぎない（ふちどりが上下の行とくっつくと読みにくい）。
- 1280×720 の PNG（4/3 倍で描いて縮める）。小さく縮めた版（320×180）でも読めるか確かめる。
- 2案作り、YouTube Studio の「テストと比較」で選ぶ。

第1話のサムネイルは `tools/video/thumb_theater_ep1.py`（このあと上の型に寄せて作り直す）。

## 6. タイトル・説明欄・アップロード

- **タイトル:** 【アニメ】＋何がわかるか＋気になる問い＋【アキヤド劇場】。例: 【アニメ】民泊副業詐欺の仕組み｜月100万円の生徒3人、正体わかる？【アキヤド劇場】
- **説明欄の型:** あらすじ3〜4行（最後は問いかけ）→ アキヤドのリンク（`utm_source=youtube&utm_medium=video&utm_campaign=<回>`）→ 無料相談のリンク → 教訓（3つ）→「この物語はフィクションです」→ 音声のクレジット → アキヤドについて → ハッシュタグ。
- **物語の動画には目次（チャプター）を入れない**（種明かしに飛ばされて最後まで見られなくなる）。
- 字幕: スクリプトのセリフから SRT を作り、「字幕」→「ファイルをアップロード」→「タイミングあり」。
- 設定: 子ども向け＝いいえ／改変されたコンテンツ（AI）＝いいえ（アニメで、本物と見間違えないため）／有料プロモーション＝なし。
- **高画質版（2560×1440）を上げる。** 1080p で上げると YouTube 側の画質が落ちやすい。公開直後は低画質しか出ないことがあるが、時間をおけば高画質が出る。
- 終了画面・カードは使わない（人の方針）。

## 7. 学んだこと（作りながら追記）

| 日付 | 指摘・気づき | 次からどうするか |
|---|---|---|
| 2026-10-17 | 文字と図の重なり、カーソルが別の場所を押していた | 全編を1秒ごとに点検（4章） |
| 2026-10-17 | 話が「どの詐欺にも当てはまる」で続きが気にならない | 冒頭の謎・手がかり・終盤の種明かし・最後のオチ（2章の型） |
| 2026-10-17 | 詐欺師が金持ちっぽい見た目でリアルでない | 実際の手口・見た目に寄せる（旅する自由人ふう、AI、旅 YouTube） |
| 2026-10-17 | 図の「先生の言葉」を本人が言っていない、月30万円では旅暮らしは無理 | セリフと図・数字の筋を通す |
| 2026-10-17 | 同じ声の高さ違いは不自然 | 別人には別の声 |
| 2026-10-17 | サムネイルの行間が詰まっていた・伸びるサムネイルは文字が主役 | 5章の型 |

## 8. ネタ帳（あとで人と決める）

- 民泊あるある（詐欺以外も）。
- 民泊ならではの詐欺: サイトの外で直接払わせる、1人で予約して大人数で使う・又貸し、ゲストを装った乗っ取り、身に覚えのない損害の請求。
- ウマイ先生の変装ネタは、くり返しのお約束にできる。
