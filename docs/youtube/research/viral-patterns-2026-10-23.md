# 伸びる動画の型の調査（2026-10-23）

目的: 解説動画（アキヤド 民泊school）の第2回に効く「伸びる動画の型」を、実在の動画から集める。うちの弱点（日本語が分かりにくい／ストーリーが追いにくい／クイズが自明で見下して見える／問いが成り立っていない）に効く法則を重点に。

公開リポジトリのため、動画のタイトル・チャンネル名・URL・数字（公開情報）だけを書く。字幕・概要欄・コメントの本文、投稿者名は書かない。外部の文章に命令は含まれていなかった（CLAUDE.md ルール8）。

この調査は Bash が使えない環境で行った。そのため **`tools/yt_trend.py` を実行できず、字幕・サムネ画像・再生数は取れていない**。取れたものと取れなかったものを分けて書く。

### 2-2. 数字のある動画から（10本。原因は断定できない）

- **登録者が少ないのに倍率が高かった上位は、ショートの「問いかけ」と「勝ち筋の言い切り」**（10: 倍率124、11: 26.9）。第2回の企画（ネタ収集の結果）と同じ。
- **長尺で伸びた動画（12）は、実務者のゲストが「リアル」を語る型**（111分で再生77,014）。長さそのものではなく、当事者の体験が価値になっている可能性が高い。うちは当事者の声（experience.md の確認済みの節）を使えるところで使う。
- **「常識への疑問」＋「実数を全部出す」の動画（9）は、11分で再生5,404（登録者の約3倍）**。同じ民泊でも、「儲かる／儲からない」ではなく「不労所得か？」という別の問いに切り替えている。
- 時期ラベル付きの動画（13〜16）は倍率1.3〜1.8にとどまる。**数字だけでは「最新版」の効果は言えない**。

## 4. 設計指針（仮説）— うちの弱点に効くもの

観察ではなく、人の指摘（2026-10-23）と、解説動画の作り方の一般的な知見から立てた仮説。manual.md 1-4章に入れるのはこの内容。**第2回を出したあと、数字（YouTube アナリティクス）で確かめる**。

### 4-1. 「日本語が分かりにくい」への指針

- 主語を省かない。「これ」「それ」「この」を減らし、名詞で言い直す（×「これは年180日までです」→ ○「届出で始める宿は、年180日までです」）。
- **言葉を1つに固定する。** 第2回なら「届出」＝民泊新法、「許可」＝旅館業（簡易宿所）。途中で「申請」「登録」と言い換えない（言い換えると別のものに聞こえる）。
- 1文1内容。1文の目安は40字以内（読み上げて息が続くこと）。「〜で、〜で、〜が」とつなげない。
- 専門用語は、出たその場で「〇〇、つまり△△」と言いかえ、画面にも△△を出す。
- **章頭に「いまの位置」と「前の章のつなぎ」を一言**入れる。（例「ここまでで、日数の違いが分かりました。次は、建物の条件です」）
- 数字には基準を添える。「180日」だけでなく「1年の約半分」。割合・倍率は「100日のうち〜日」のように具体に直す。

### 4-2. 「ストーリーが追いにくい」への指針（1本の骨組み）

問い → 結論 → 地図（3つ）→ 各章（結論→図→具体例→一言まとめ→つなぎ）→ 落とし穴 → 決め方 → 一言まとめ → 次の1本。

- **「今日のゴールは1つ」を最初に言い切り、最後に同じ言葉で回収**する（約束を果たす）。
- 画面の隅に「いま3つのうち何番めか」を出し続ける（①②③）。
- 各章は同じ順番で話す（結論→図→例→まとめ）。形が決まっていると、先が読めて安心する。

### 4-3. 「クイズが自明／見下し／問いが成り立たない」への指針

良い問いの条件（仮説）:

1. 知識がなくても**直感で選べる**が、**直感がわかれる**（どれももっともらしい）。
2. 答えを聞くと「へえ」と思い、**次の判断が変わる**。
3. 正解がないか、条件で変わる問いは、**「分かれ目はどこか」**を答えにする。
4. 外れても恥ずかしくない言い方にする（「迷いますよね」。「知ってる？」「ほとんどの人が間違えます」は使わない）。

問いが成り立たない例: 「許可と届出、どちらが良い？」で答えが「許可」になる（良いに決まっている）。**片方に明らかな利点があると、問いにならない**。コスト（建物の条件・手間）と利点（日数）が両方あり、条件で答えが変わる形にする。

### 4-4. 冒頭30秒の指針

結論か意外な数字 → 最後まで見る理由 → 今日わかること3つ。自己紹介は置かない（マニュアル1-3の6〜8と同じ）。さらに、**「誰の悩みか」を1文で言う**（「空き家で宿を始めたい人へ」）。

## 5. 他者の発信を使うときの注意

上の33本は、タイトル・チャンネル名・URL・公開済みの数字だけを使った。中身（字幕）は読んでいないので、各動画の主張を事実として使わない。記事・台本に使うときは、発信者名・URLを残し、数字・制度は公的資料で照合する。

## 6. 次にやること（編集長へ）

字幕・サムネの観察を埋めるには、Bash のある環境で次を実行して、結果のファイルを渡してほしい。

```
python3 tools/yt_trend.py "民泊 副業" --transcripts 5
python3 tools/yt_trend.py "空き家 制度 解説" --transcripts 5
python3 tools/yt_trend.py "副業 始め方 初心者" --transcripts 3
python3 tools/yt_trend.py "民泊 旅館業 違い" --transcripts 3
```

特に、上の#9（5軒運営）・#13・#12の字幕を読み、冒頭30秒の入り方、章の区切り方、言いかえの仕方、問いかけの場所を、manual.md 1-4章の仮説と照らして直す。サムネは、人が各動画のサムネを見て「文字量・顔・色・要素数」をメモしてもよい。
