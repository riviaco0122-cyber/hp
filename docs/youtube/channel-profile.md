# YouTube チャンネルのプロフィール（説明・キーワード・リンク）

YouTube Studio の「カスタマイズ → プロフィール」に貼る文面。変えたらここも直す（このファイルが正本）。
アイコン・バナーの作り方は `manual.md` 0章。

## 説明（1000字まで）

```
民泊戦略家「アキ」が、空き家と民泊の専門知識を、誰にでもわかりやすく解説するチャンネルです。

「民泊って、本当にもうかるの？」
「親の家が空き家になったら、どうすればいい？」
「副業で宿をはじめるには、何から？」

そんな疑問に、結論からお答えします。
難しい言葉は使いません。1本の動画で、1つの「わかった！」を持ち帰ってもらうことを約束します。

■ このチャンネルでわかること
・民泊・空き家を「資産」として考える戦略
・宿をはじめるまでの手続きとお金（初期費用・税金・利回りの考え方）
・空き家を売る・貸す・宿にする、の判断のしかた
・集客と運営（インバウンド・稼働率・料金の決め方）
・アニメで見る「民泊のよくある失敗・詐欺の手口」（アキヤド劇場）

■ 私たちについて
運営は、空き家と民泊のメディア「アキヤド」を手がける合同会社RIVIA&CO.。
私たち自身が静岡県下田市で宿を開業・運営し、空き家の活用を支援しています。
動画の数字は、実際の運営の実績や、公的な統計にもとづいています（出典は各動画の説明欄に記載）。

■ もっと詳しく知りたい方へ
空き家と民泊のメディア「アキヤド」の記事や、空き家・民泊の無料相談は、このページ上の「リンク」からどうぞ。

※ 動画は情報提供を目的としたもので、特定の投資を勧めるものではありません。
音声: VOICEVOX
```

## リンク（プロフィールの「リンク」。チャンネル名の下に押せるリンクとして出る）

チャンネルの説明に書いた URL は、押せない文字のままになる。押せるリンクは、ここ（「カスタマイズ → プロフィール → リンク → リンクを追加」）にだけ入れる。説明には URL を書かない。

| 表示名 | URL |
|---|---|
| アキヤド（空き家と民泊のメディア） | https://rivia-co.com/media.html?utm_source=youtube&utm_medium=channel |
| 無料相談 | https://rivia-co.com/contact.html?utm_source=youtube&utm_medium=channel |

## メモ

- 体験として書いてよいのは `docs/brand/experience.md` の「人が確認済み」の節だけ（下田の宿＝創業メンバーが開業・運営）。ほかの施設名・数・取引先は書かない。
- 省庁・機関の名前は、説明でも前に出さない（出典は各動画の説明欄の下にだけ書く）。

## ほかの SNS のプロフィールのリンク（GA4 で計測できる URL）

プロフィールのリンクは1つの固定の URL にして、毎回の投稿で変えない。`utm_medium=social` にすると、GA4 の「集客 → トラフィック獲得」で「Organic Social」にまとまり、参照元が instagram／tiktok と分かれて見える。

| SNS | プロフィールに貼る URL |
|---|---|
| Instagram | https://rivia-co.com/media.html?utm_source=instagram&utm_medium=social&utm_campaign=profile |
| TikTok | https://rivia-co.com/media.html?utm_source=tiktok&utm_medium=social&utm_campaign=profile |
