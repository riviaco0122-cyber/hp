## 3. 絵の方針（人の指摘 2026-10-23「イラストの品質が低い。もっとお金をかけている感じにしてほしい」）

第1回は、フラットな図形と単色の背景が中心で、「作り込み」が足りなかった。第2回は、すべての章の絵を次の5点で上げる。台本の担当と動画班は、各章で「何を足したか」を確かめる。

1. **背景に奥行き:** 空・遠景の山・海・街並みの3層（`bg()` の層を使い、層ごとにゆっくり動かす）。章ごとに時間帯・季節を変える（朝の宿、夕方の町、夜のゲスト到着 など）。単色ベタ塗りの背景は使わない。
2. **質感と影:** 木目・瓦・障子・畳の質感パターン。床に落ちる影、建物の落ち影、ものの下のやわらかい影。ガラス・紙・カードにはうっすらハイライト。
3. **小物を足す:** 宿の絵にはスーツケース、提灯、植木、自転車、郵便ポスト、鍵、スマホの予約画面、看板。章の主題に合う小物を必ず3つ以上。
4. **色の深み:** ブランドカラー（緑 `#2e6b47`・濃い緑 `#1f3a2b`・オレンジ `#cf5f37`・黄 `#f0b35a`）を、同系色のグラデーション（明・中・暗の3段）と補色の差し色で使う。べったり1色にしない。
5. **動き:** 図は、ふわっと出て、少し弾む。カレンダーはめくれる、日数は1日ずつ塗られる、鍵は回る、煙突の煙や雲、揺れる暖簾、きらめき。5〜10秒ごとに何かが動く。止まった絵を5秒以上出さない。

章ごとの具体は4章の「見せる図」に書いた。点検は、`layout_check.py` に加えて、**章ごとに代表コマを1枚ずつ書き出し、第1回の同じ位置のコマと並べて「質感・影・小物・動き」が増えているか**を確かめる。

## 4. 章立て（目標: 台本 2,600〜2,900字、約9分）

### 章0 オープニング（0〜3.5秒）
毎回同じ（緑の幕 → ロゴ → 「アキヤド 民泊school」→ 呼び込み）。第1回の実装をそのまま使う。

### 章1 つかみ（約0:04〜0:50）
- **ひとことの結論:** 空き家で宿を始めるなら、まず「届出」か「許可」かを決める。選び間違えると、1年に泊められる日数が半分になる。
- **セリフの流れ（自己紹介なし）:**
  1. 「結論から言います。同じ空き家でも、届出で始めると1年に泊められるのは180日まで。許可なら365日。この差は、稼働率にすると約49%の天井です。」
  2. 「実は私たちの宿は、開業から約8.5か月の平均で稼働率が約53%。この水準が1年続けば、年180日の天井を超える計算です。」（体験: 3-2 の確認済み。「旅館業法の簡易宿所で許可を取った。年180日の制限を避けて通年営業のため」、稼働率は運営事例の記事の数字。実績の数字なので「一例」と添える）
  3. 最後まで見る理由: 「最後に、あなたの家がどちらに向くか、3つの質問で決められるようにします。」
  4. 今日わかること3つ（目次の図）: ①2つの制度の違い ②天井が変わる仕組み ③失敗しない選び方。
- **見せる図:** 左右に分かれた2つの宿（家A=届出の小さな看板、家B=許可の看板）。カレンダー365マスが、家Aだけ途中（180マス目）で黒いシャッターが降りる。夕焼けの町並み、提灯が灯る。
- **数字と出典:** 年180日（住宅宿泊事業法）、180÷365＝約49%（計算）。稼働率約53%（運営事例の記事。experience.md 3-2）。
- **体験:** 上記。宿の数字は「試運転・手間と初期投資は含まない」系の注意は不要（稼働率のみ）だが、「1つの例」と言う。

### 章2 そもそも、泊めるには手続きが要る（約0:50〜1:50）
- **ひとことの結論:** お金をもらって人を泊めるなら、入口は2つ。届出で入る「民泊新法」か、許可で入る「旅館業」。
- **見せる図:** 入口の門が2つ（小さな木戸と、大きな玄関）。木戸に「届出」、玄関に「許可（保健所）」。「少し貸すだけ」でも手続きが要る、を吹き出しで。
- **内容:** 民泊新法の正式名称は住宅宿泊事業法で、2018年6月に施行。旅館業の許可の一種が簡易宿所（小さな宿向け）。国が指定した区域だけで使える特区民泊もあるが、今日は2つに絞る、と一言。
- **名乗り:** 章の終わりに「民泊戦略家のアキです。ここからは、違いを3つに分けて見ていきます」の一文だけ。
- **数字と出典:** 2018年6月施行、旅館業法の許可が原則必要（記事の参考資料: 観光庁の民泊制度ポータルサイト、厚生労働省の旅館業法のページ、国土交通省の住宅宿泊事業法のページ。画面・ナレーションには出さず、「国は」と言う）。

### 章3 違い① 泊められる日数（約1:50〜3:50）★中心の章
- **ひとことの結論:** 届出は年180日まで。1年の約49%。条例でさらに短くなることもある。許可は上限なし。
- **見せる図:** 365日のカレンダー（1日ずつ塗られていく）。180日で止まる緑の帯と、残り185日の灰色。稼働率の目盛りに 49% の天井線、そこに「私たちの宿 約53%」の旗が突き抜ける。
- **クイズ（中だるみ防止）:** 「年180日は、1年の何割でしょう？ A 3割 B 5割 C 7割」→ 正解 B（約49%）。カウントダウンつき。
- **内容:** （29.6%の全国平均は一次出典で未照合のため動画では使わない）稼働率49%の宿は1年で約180日泊まる計算。混む時期に強い宿、通年で運営する宿ほど、天井が先に来る。逆に、「ときどき使う家」「まず小さく試す」なら、天井は気にならない。売上の天井は「泊められる日数 × 1泊の料金」。
- **体験（確認済み 3-2）:** 私たちは、年180日の制限を避けて通年で営業するために、旅館業の簡易宿所の許可を選んだ。
- **数字と出典:** 年180日（住宅宿泊事業法）、約49%（計算。180÷365）、開業から約8.5か月の平均稼働率 約53%（運営事例の記事。12か月分ではない）。

### 章4 違い② 手続きと建物の条件（約3:50〜5:50）
- **ひとことの結論:** 届出は「住宅のまま」で軽い。許可は建物の条件が厳しいが、住居専用地域でなければ通年で営業できる。
- **見せる図:** 比べる表を、絵で。左: 台所・浴室・便所・洗面がそろう「住宅」の家。右: 図面・消防設備（火災報知器・誘導灯）・保健所の判子つきの家。下に立地の地図（住居専用地域は緑の網掛け: 新法○ 簡易宿所×=原則不可）。
- **内容（記事の比較表の範囲だけ）:**
  - 手続き: 届出（都道府県等）／許可（保健所）。
  - 建物: 住宅の設備がそろっていること／簡易宿所の構造設備の基準。
  - 広さの目安: 10人未満なら1人あたり3.3㎡。たとえば4人なら13.2㎡。10人以上は33㎡以上。（旅館業法施行令。簡易宿所の許可の記事に条文あり。新法側の「1人あたり3.3㎡以上」と並べる）
  - 立地: 住居専用地域でも可能（条例で制限あり）／住居専用地域などでは原則営業できない。
  - 管理: 家主が不在になる宿は、住宅宿泊管理業者への委託が必要／施設ごとに管理体制を整える。
  - 宿に使う部分が200㎡を超えると、用途変更の確認申請が要る（簡易宿所の許可の記事）。
- **体験（確認済み 3-2）:** 保健所と消防署に、開業の2か月前に事前相談して、申請は自分で行った。申請から許可まで1〜2か月。許可番号がないと Airbnb で予約を受けられなかった。「下田の1件の経験で、どこでも同じとは限りません」と添える。
- **数字と出典:** 3.3㎡×人数・33㎡（旅館業法施行令）、200㎡（建築基準法）、記事の比較表。

### 章5 違い③ 向く人は誰か（約5:50〜6:50）
- **ひとことの結論:** 小さく試すなら届出。通年で事業にするなら許可。目的で決める。
- **見せる図:** 道が2本に分かれる分かれ道の看板。左「ときどき使う家／まず試す／住居専用地域」→ 届出。右「通年／稼働日数で回収／一棟貸しを本格運営」→ 許可。道の先に、それぞれ違う季節の風景。
- **内容:** 記事の「目的別」の3対3をそのまま。ここでユウタが「届出で試して、あとから許可には変えられますか？」と聞く。**答えは出典がないので言い切らない**（「自治体と物件によるので、窓口で確かめて。ここは地域で違います」）。
- **数字と出典:** なし（記事の目的別の整理）。

### 章6 落とし穴 4つ（約6:50〜8:00）
- **ひとことの結論:** 失敗は、買ったあとに気づくこと。家を買う前に、役所に相談する。
- **見せる図:** 4枚のカード（買ってから許可不可／消防設備の費用の見落とし／条例による営業制限／近隣への説明不足）が1枚ずつ落ちて、落ちた所に小さなアイコン（×印の家、消火器、条例の巻物、ごみ袋）。
- **内容:** 記事の「失敗1〜4」。消防設備は、取材事例（匿名の会社員オーナー）で「想定約40万円が約60万円（約1.5倍）になった」。個人の事例で一般化できない、と添える。劇場の「うまい話」とつなぐ一言: 「『許可なんて簡単』『届出だけで通年OK』と言われたら、まず疑ってください。」
- **体験（確認済み 3-2）:** Wi-Fi 工事の車両の駐車で近隣から指摘を受けた（近隣への配慮の例）。
- **数字と出典:** 消防設備 約40万→約60万円（記事「空き家を旅館業で民泊に」の取材事例。2025年12月・本人申告）。

### 章7 あなたの家はどっち？（3つの質問）→ まとめ → 次の行動（約8:00〜9:10）
- **ひとことの結論:** ①何日泊めたいか ②家の立地と広さ ③誰が運営するか。この3つで決まる。
- **見せる図:** 3つの質問のフローチャート（Yes/No で分岐し、届出か許可に着地する）。最後に1枚のまとめ図（天井49%の目盛り＋2つの門）。夕焼けから夜になる背景で、宿に灯りがともる。
  - 質問1: 年180日（約49%）で足りる？ → 足りる＝届出も候補／足りない＝許可。
  - 質問2: 住居専用地域？ 広さは？ → 住居専用地域＝許可は原則むずかしい／広さが基準を超える（200㎡超など）＝窓口に相談。
  - 質問3: 家主が不在になる？ → 届出は管理業者への委託が必要。許可は自前の管理体制。
- **まとめ（短く）:** 「日数・立地・運営。迷ったら、家を買う前に役所へ。」
- **次の行動:** ①説明欄の記事（制度の比較表）。②許可の取り方の記事。③無料相談。次に見る動画は1本だけ、理由つきで: 「第1回『民泊は第3の資産』。天井が49%と知ったうえで、宿を資産に入れる理由を見ると、制度選びの意味がわかります」。固定コメントで問いかけ「あなたの家は、届出と許可のどちらに向きそうですか？」。
- **注意書き（最後の画面）:** 情報提供が目的で、特定の選択を勧めるものではない。制度は変わる、自治体で違う。

## 7. リール（45〜60秒）

- **候補区間:** 章3の中心。「結論から言います」の続きではなく、章3の「年180日は、1年の何割か」のクイズ → 正解（約49%）→ 「私たちの宿の稼働率は約53%。天井にぶつかる」 → 「だから日数で制度を選ぶ」まで。章3のクイズのセリフ（「ここでクイズです。年180日は〜」）から、「天井に先にぶつかります」のセリフまで。台本ができたら `make_reel.py` の「場面.セリフ」の番号を決める（目安 約50秒）。注意のセリフ（「一例で、どの宿でも同じではない」）まで切らずに入れる。
- **見出し（2行・問いの形）:** 「年180日って、/ 1年の何割か知ってる？」
