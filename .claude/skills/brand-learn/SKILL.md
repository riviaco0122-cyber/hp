# ブランド学習

1. `brand-learner` に `docs/brand/` の作成（初回）または見直し（2回目以降）を依頼する。
2. 結果のファイルを確認し、出所のない実績・数値が混じっていないか自分でも点検する。
3. コミットして push し、PR を作る。PR には「人が直してほしい箇所」（特に `philosophy.md` と `experience.md`）を挙げる。人が確認した節には `<!-- 人が確認済み -->` を付けてもらうよう案内する。
